# Word Race Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 60-second, four-choice game played with the user's own My Words list, on web and mobile, as specified in `docs/superpowers/specs/2026-11-25-word-race-design.md`.

**Architecture:** All rules live in `shared/word-race.ts` (pure, `now` and `rng` passed in) and are used by both apps. Each app adds a thin storage helper (best score + the offline copy of the list) and one screen. Nothing new on the server.

**Tech Stack:** Next.js client page, Expo Router 57 + NativeWind, vitest on both sides.

**Conventions:** branch `feature/words-race`; conventional commits; stage by explicit path and run `git diff --cached --name-only` before each commit; every file ends with a newline. Web tests: `npx vitest run <file>` from the root. Mobile tests: `npx vitest run <file>` from `mobile/`. Type checks: `npx tsc --noEmit` (root) and `npx tsc --noEmit -p .` (`mobile/`). Lint: `npm run lint` (root).

## Decisions the spec leaves open

1. **Too few distractors.** Same-clue exclusion can leave fewer than three other words (e.g. four askable words, two with the same meaning). The question then shows fewer choices; it never loops looking for more.
2. **Tap rules live in the state.** `pickRace` stores the pick (`picked`) and ignores taps while one is stored or at/after the deadline; `nextRaceQuestion` clears it. The screens only wait 600 ms and call `nextRaceQuestion` if the round is not over.
3. **Clues are folded once.** `startRace` computes every askable word's clue and its comparison key once (Hermes on Android sends non-ASCII case changes through JNI), using the same İ/I/ı rule as the My Words search (`searchFold`, now exported from `shared/vocab.ts`).
4. **Masking** uses `(^|[^A-Za-z])(word(?:s|es|ed|d|ing)?)(?![A-Za-z])` with the `gi` flags, replaced by `$1___`; no lookbehind.
5. **The offline copy belongs to one account.** It is stored as the word rows (they carry `user_id`). A copy whose rows belong to another user is ignored when the user is known (web: the session; mobile: `useAuth().user`, which can be null offline after a cold start). Mobile sign-out removes the copy. Parsing is fail-soft (anything malformed reads as no copy).
6. **Mobile gate offline.** The My Words screen saves the list as the offline copy after each successful read, and when the read fails it decides the race button from that copy, so an offline race stays reachable.
7. **The race starts as soon as its list is read.** The My Words button is the start; "Play again" reads the list again (with the offline fallback) and starts a new round.
8. **Missed words** are listed once each, in the order first missed.

### Task 1: Shared game logic

**Files:** create `shared/word-race.ts`, `src/lib/word-race.ts`, `src/lib/word-race.test.ts`; modify `shared/vocab.ts` (export `searchFold`).

API:

```ts
export const RACE_MS = 60_000;
export const RACE_PENALTY_MS = 3_000;
export const RACE_FEEDBACK_MS = 600;
export const RACE_TICK_MS = 250;
export const RACE_MIN_WORDS = 4;
export const RACE_CHOICES = 4;
export const RACE_COMBO_SHOWN = 3;
export const RACE_BEST_KEY = "words-race-best";
export const RACE_LIST_KEY = "words-race-list";

export interface RaceChoice { id: string; word: string }
export interface RaceQuestion { id: string; clue: string; choices: RaceChoice[] }
export interface RacePick { id: string; correct: boolean }
export interface RaceState {
  words: VocabWord[];            // the whole list, for distractors
  clues: Record<string, string>; // askable id -> clue text
  keys: Record<string, string>;  // askable id -> folded clue (same-clue test)
  deck: string[];                // askable ids still to ask in this pass
  question: RaceQuestion;
  endsAt: number;
  score: number;
  combo: number;
  bestCombo: number;
  missed: string[];
  picked: RacePick | null;
}

raceClue(word): string | null
raceWords(words): VocabWord[]
canRace(words): boolean
startRace(words, now, rng = Math.random): RaceState | null
pickRace(state, id, now): RaceState
nextRaceQuestion(state, rng = Math.random): RaceState
raceTimeLeft(state, now): number   // ms, never below 0
raceOver(state, now): boolean      // now >= endsAt
parseRaceList(raw: string | null, userId: string | null): VocabWord[] | null
```

- [ ] **Step 1: Write the failing tests** covering:
  - `raceClue`: Turkish meaning first; else the first definition with the word masked (case-insensitive; `-s`, `-es`, `-ed`, `-d`, `-ing`; whole words only, so `budgetary` stays); multi-word words (`give up`); null when neither.
  - `raceWords`/`canRace`: learned words count; words with no clue do not; four askable needed.
  - `startRace`: null below four; 60 s deadline from `now`; question has the answer among its choices, four distinct choices, choices may include unaskable words, never a word whose clue matches the answer's (case and spacing ignored, İ/ı folded); fewer choices when not enough others exist.
  - Deck: every askable word comes once before any repeats; never the same word twice in a row across a reshuffle (seeded rng).
  - `pickRace`: right adds 1 and raises combo/bestCombo; wrong moves `endsAt` 3 s earlier, resets combo, adds the word to `missed` once; a second tap before `nextRaceQuestion` is ignored; taps at/after the deadline are ignored; a penalty that crosses the deadline ends the round at once.
  - `nextRaceQuestion`: does nothing without a pick; clears the pick and moves on.
  - `raceTimeLeft`/`raceOver` at, before and after the deadline.
  - `parseRaceList`: null for null/garbage/non-array/rows missing fields; rows of another user ignored when `userId` given; accepted when `userId` is null.

### Task 3: Web offline copy + race screen + My Words button

**Files:** create `src/lib/word-race-list.ts` (+ `.test.ts`), `src/app/words/race/page.tsx`; modify `src/app/words/page.tsx`, `src/app/words/page.test.ts`, `src/lib/app-lock-gate.test.ts`.

- `readRaceList(userId)` = `parseRaceList(localStorage.getItem(RACE_LIST_KEY), userId)` inside try/catch (null on error); `writeRaceList(words)` = `setItem(JSON.stringify(words))`, errors swallowed.
- Page: signed-out → `/`. On sign-in: `listWords()`; success → `writeRaceList`, start; failure → `readRaceList(sessionUserId)`; a raceable copy starts the race, otherwise "could not load" + Retry. A list that cannot race shows `wordRaceNeedWords` + back link.
- Playing: `setInterval(RACE_TICK_MS)` updates `now`; a tap calls `pickRace(state, id, Date.now())`, sets `now`, then a 600 ms timeout calls `nextRaceQuestion` unless the round is over. Both timers cleared on unmount and at round end.
- Header: time left (`Math.ceil(ms / 1000)`), score, combo when ≥ 3. Choices: green for the answer and red for a wrong pick while `picked` is set.
- End: score, best combo, best (+ New best!), missed words with their clues, Play again, Back to my words. Best: `sessionRead` in a mount effect, `bestAfter` + `writeSavedBest` when the round ends (as `TowerGame.tsx`).
- My Words: under the review button, a link to `/words/race` when `canRace(words)`, else a disabled span plus the hint.
- Tests (fake `setInterval`/`setTimeout`/`Date`, stubbed `localStorage`): starts and shows a clue + four choices; right answer scores, wrong one shows the red pick and costs 3 s; taps during the pause are ignored; round ends at 0 with the end screen and missed word; New best is saved; offline copy used when the read fails; a copy of another user is ignored; too few words shows the hint; button enabled/disabled on My Words; signed-out goes home; `lockScreenFor("/words/race", game)` is `"game"`.
