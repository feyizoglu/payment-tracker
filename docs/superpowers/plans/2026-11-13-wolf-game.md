# Wolf Night Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Wolf Night (TR Kurt Gecesi), a hidden-roles party game for one phone, to the Games section on web and mobile, working offline like Imposter.

**Architecture:** All rules live in a pure module `shared/wolf-game.ts`: setup validation, the wolf suggestion, the deal with an injected `Rng`, night resolution, the win check and a reducer whose actions carry their time (`at`) and pass Imposter's tap guard. Each platform has thin screen components under `wolf/` that render the reducer state; the container on each platform renders only other components. The This game screen is a reducer phase (`rules`) that sits before every deal; the same screen opens over the game from a Rules button as local UI state. Night visits reuse Imposter's `DealTurn` hold card (with one new optional prop, `nextLabel`) and the narrator hand-over reuses `PassPhone`.

**Tech Stack:** Next.js 16 (client components, Tailwind v4), Expo SDK 57 + NativeWind 4 + expo-router, vitest (node environment; components are called as plain functions).

**Spec:** `docs/superpowers/specs/2026-11-13-wolf-game-design.md`

## Decisions this plan takes (the spec leaves them open)

1. **Default setup:** Seer and Doctor on, Hunter and Witch off, Pass the phone, timer off, roles of removed players shown.
2. **Night visit = held card, then an open choice screen.** A choice cannot sit inside the held card (on touch the hold is a single responder, a second finger's tap cancels it), so a visit is `DealTurn` (role + task + the earlier wolves' picks, or the witch's victim and potions) with the button "Continue", then a choice screen on the visitor's colour that reads the same for every role ("Choose a player"). Next player is enabled once a pick is made. The seer's first pick is final and its answer shows at once under the choices.
3. **Witch lap:** everyone but the witch only holds the card ("Nothing to do this lap") and taps Continue; the witch gets the choice screen with Heal and Poison. Her visit is longer, which tells the table a witch with a potion is alive; the spec accepts that.
4. **Hunter:** the shot comes before the win check (so a shot can still take a parity win from the wolves), except when no wolf is left: the village has won whatever the hunter does, so no shot is asked for.
5. **Narrator:** after the deal the phone goes to the narrator (`PassPhone` on a neutral grey) whose roster lists every role. On the night script the narrator's player buttons show each player's role. Lines for removed roles are read with the marker and need no choice; the witch's line is read even with no potion left. The narrator may correct a tap before Next.
6. **Tap guard:** every action is ignored inside `TAP_GUARD_MS` of the last accepted move; a pick (or the witch's Heal) does not move a turn on and does not restart the guard.
7. **Rules button** on the deal and visit cards, the narrator's night, the morning and the day's talk. It opens the This game screen without Deal; Close returns to the same place (the reducer state, including the day timer's end time, is untouched).
8. **This game screen** has Back (to the setup) next to Deal the cards.

```ts
import { describe, it, expect } from "vitest";
import { translationsFor } from "@/lib/i18n";
import * as W from "@/lib/wolf-game";

type WolfSetup = W.WolfSetup;

const NAMES = ["Ann", "Bob", "Cem", "Dan", "Eda", "Fay", "Gil", "Hal", "Ivy", "Jon", "Kim", "Lea"];
const players = (n: number) => NAMES.slice(0, n);
const setup = (over: Partial<WolfSetup> = {}): WolfSetup => ({ ...W.DEFAULT_SETUP, players: players(5), ...over });
const en = translationsFor("en");
const tr = translationsFor("tr");

describe("wolf suggestion", () => {
  it("suggests 1 wolf for 5 to 7 players, 2 for 8 to 11 and 3 for 12", () => {
    expect([5, 6, 7, 8, 11, 12].map(W.suggestWolves)).toEqual([1, 1, 1, 2, 2, 3]);
  });

  it("follows the player count until the wolves are set by hand", () => {
    expect(W.wolfCount(setup({ players: players(8) }))).toBe(2);
    expect(W.wolfCount(setup({ players: players(12) }))).toBe(3);
    expect(W.wolfCount(setup({ players: players(12), wolves: 1 }))).toBe(1);
  });

  it("keeps the wolves fewer than the other players", () => {
    expect([5, 6, 7, 12].map(W.maxWolves)).toEqual([2, 2, 3, 5]);
  });
});

describe("validateSetup", () => {
  it("accepts 5 to 12 named players", () => {
    expect(W.validateSetup(setup())).toEqual([]);
    expect(W.validateSetup(setup({ players: players(12) }))).toEqual([]);
  });

  it("reports only the player error below 5 players", () => {
    expect(W.validateSetup(setup({ players: players(4), wolves: 3, specials: [...W.SPECIAL_ROLES] }))).toEqual([
      "tooFewPlayers",
    ]);
  });

  it("reports too many, blank and repeated names", () => {
    expect(W.validateSetup(setup({ players: [...players(12), "Max"] }))).toContain("tooManyPlayers");
    expect(W.validateSetup(setup({ players: ["Ann", " ", "Cem", "Dan", "Eda"] }))).toEqual(["blankName"]);
    expect(W.validateSetup(setup({ players: ["Ann", "ann ", "Cem", "Dan", "Eda"] }))).toEqual(["duplicateName"]);
  });

  it("needs at least one wolf and fewer wolves than other players", () => {
    expect(W.validateSetup(setup({ wolves: 0 }))).toEqual(["wolfCount"]);
    expect(W.validateSetup(setup({ wolves: 2, specials: [] }))).toEqual([]);

  it("allows wolves and special roles up to the player count", () => {
    expect(W.validateSetup(setup({ wolves: 1, specials: [...W.SPECIAL_ROLES] }))).toEqual([]);

  it("sends each error to the step that can fix it", () => {
    const bad = setup({ players: ["Ann", "", "Cem", "Dan", "Eda"], wolves: 2, specials: [...W.SPECIAL_ROLES] });
    expect(W.stepErrors(bad, "players")).toEqual(["blankName"]);
    expect(W.stepErrors(bad, "roles")).toEqual(["tooManyRoles"]);
    expect(W.stepErrors(bad, "rules")).toEqual([]);
  });

  it("has a message for every error in both languages", () => {
    for (const key of Object.values(W.SETUP_ERROR_KEYS)) {
      expect(en[key]).toBeTruthy();
      expect(tr[key]).toBeTruthy();

  });

describe("roles in play", () => {
  it("lists the wolves first, then the special roles in a fixed order, then the villagers", () => {
    expect(W.rolesInPlay(setup({ players: players(9), specials: ["witch", "seer"] }))).toEqual([
      { role: "wolf", count: 2 },
      { role: "seer", count: 1 },

      "hunter",
      "witch",

  });

    for (const keys of [W.ROLE_NAME_KEYS, W.ROLE_DESC_KEYS]) {
      for (const key of Object.values(keys)) {

    for (const raw of [null, "", "{", "[]", "42"]) expect(W.parseSavedSetup(raw)).toEqual(W.DEFAULT_SETUP);

  it("reads back a saved setup", () => {

    expect(W.parseSavedSetup(JSON.stringify({ players: ["Ann"] })).specials).toEqual(W.DEFAULT_SETUP.specials);
  });
```

```ts
export function validateSetup(setup: WolfSetup): SetupError[] {
  const errors: SetupError[] = [];
  const names = setup.players.map((p) => p.trim());
  if (names.length < MIN_PLAYERS) errors.push("tooFewPlayers");
  if (names.length > MAX_PLAYERS) errors.push("tooManyPlayers");
  if (names.some((n) => n === "")) errors.push("blankName");
  const keys = names.filter((n) => n !== "").map((n) => n.toLocaleLowerCase());
  if (new Set(keys).size !== keys.length) errors.push("duplicateName");
  // With too few players the player error already explains it; do not add a second one.
  if (names.length < MIN_PLAYERS) return errors;
  const wolves = wolfCount(setup);
  if (!Number.isInteger(wolves) || wolves < 1 || wolves >= names.length - wolves) errors.push("wolfCount");
  if (wolves + setup.specials.length > names.length) errors.push("tooManyRoles");
  return errors;
}
```

```ts
function pickIndex(length: number, rng: Rng): number {
  return Math.min(length - 1, Math.floor(rng() * length));
}

/** `result[seat]` is that player's role. */
export function dealRoles(setup: WolfSetup, rng: Rng): Role[] {
  const deck = rolesInPlay(setup).flatMap(({ role, count }) => Array.from({ length: count }, () => role));
  for (let i = deck.length - 1; i > 0; i--) {
    const j = pickIndex(i + 1, rng);
    [deck[i], deck[j]] = [deck[j], deck[i]];
  }
  return deck;
}

export function otherWolves(roles: Role[], seat: number): number[] {
  return roles.flatMap((role, i) => (role === "wolf" && i !== seat ? [i] : []));
}

export function winner(roles: Role[], alive: boolean[]): Side | null {
  const wolves = roles.filter((role, i) => alive[i] && role === "wolf").length;
  const others = roles.filter((role, i) => alive[i] && role !== "wolf").length;
  // In this order, so the village wins when both hold at once.
  if (wolves === 0) return "village";
  if (wolves >= others) return "wolves";
  return null;
}

/** The living seats in the order the phone visits them on night `nightNumber` (from 1). */
export function visitOrder(alive: boolean[], nightNumber: number): number[] {
  const n = alive.length;
  if (n === 0) return [];
  const start = (nightNumber - 1) % n;
  return Array.from({ length: n }, (_, k) => (start + k) % n).filter((seat) => alive[seat]);
}

/** `picks[seat]` is whom that seat chose; only the wolves' picks count. */
export function wolvesVictim(picks: (number | null)[], roles: Role[], rng: Rng): number | null {
  const counts = new Map<number, number>();
  picks.forEach((target, seat) => {
    if (target !== null && roles[seat] === "wolf") counts.set(target, (counts.get(target) ?? 0) + 1);
  });
  if (counts.size === 0) return null;
  const top = Math.max(...counts.values());
  const leaders = [...counts.keys()].filter((target) => counts.get(target) === top).sort((a, b) => a - b);
  return leaders.length === 1 ? leaders[0] : leaders[pickIndex(leaders.length, rng)];
}

export interface NightOutcome {
  victim: number | null;
  /** The doctor's pick. */
  protect: number | null;
  /** The witch used the healing potion on the victim. */
  heal: boolean;
  poison: number | null;
}

/** Who leaves the game in the morning, in seat order. */
export function nightRemovals(night: NightOutcome): number[] {
  const removed = new Set<number>();
  // The doctor and the healing potion stop only the wolves; the poison cannot be stopped.
  if (night.victim !== null && night.victim !== night.protect && !night.heal) removed.add(night.victim);
  if (night.poison !== null) removed.add(night.poison);
  return [...removed].sort((a, b) => a - b);
}

export type NarratorLine = "sleep" | "wolves" | "seer" | "doctor" | "witch" | "wake";

export const NARRATOR_LINE_KEYS = {
  sleep: "wolfLineSleep",
  wolves: "wolfLineWolves",
  seer: "wolfLineSeer",
  doctor: "wolfLineDoctor",
  witch: "wolfLineWitch",
  wake: "wolfLineWake",
} as const satisfies Record<NarratorLine, string>;

// The hunter acts only when removed, so it has no line.
export function narratorLines(setup: WolfSetup): NarratorLine[] {
  const called = (["seer", "doctor", "witch"] as const).filter((role) => setup.specials.includes(role));
  return ["sleep", "wolves", ...called, "wake"];
```

```ts
// The buttons that move a turn on sit where the next screen's buttons appear, so a
// double tap would otherwise also press the next one, often for the next player.
function tooSoon(state: GameState, at: number): boolean {
  const d = at - state.lastActionAt;
  return d >= 0 && d < TAP_GUARD_MS;
}

function beginNight(state: GameState, at: number): GameState {
  const number = (state.night?.number ?? 0) + 1;
  return {
    ...state,
    phase: "night",
    night: {
      number,
      lap: "main",
      order: visitOrder(state.alive, number),
      visit: 0,
      stage: "card",
      picks: state.roles.map(() => null),
      line: 0,
      victim: null,
      seen: null,
      protect: null,
      heal: false,
      poison: null,
    },
    removal: null,
    revealed: false,
    lastActionAt: at,
  };
}

function dealStep(state: GameState, action: GameAction): GameState {
  if (action.type === "reveal") {
    if (state.revealed) return state;
    return { ...state, revealed: true, lastActionAt: action.at };
  }
  if (action.type !== "next" || !state.revealed) return state;
  const turn = state.turn + 1;
  const n = state.setup.players.length;
  // In narrator mode the phone then goes back to the narrator: one more turn, the roster.
  if (turn < n || (turn === n && state.setup.night === "narrator")) {
    return { ...state, turn, revealed: false, lastActionAt: action.at };
  }
  return beginNight(state, action.at);
}

export function gameReducer(state: GameState, action: GameAction): GameState {
  if (tooSoon(state, action.at)) return state;
  switch (action.type) {
    case "start": {
      if (state.phase !== "setup" || validateSetup(action.setup).length > 0) return state;
      const setup = { ...action.setup, players: action.setup.players.map((p) => p.trim()) };
      return { ...initialGameState(setup), phase: "rules", lastActionAt: action.at };
    }
    case "deal": {
      if (state.phase !== "rules") return state;
      const roles = dealRoles(state.setup, action.rng);
      return { ...initialGameState(state.setup), phase: "deal", roles, alive: roles.map(() => true), lastActionAt: action.at };
    }
    case "playAgain":
      if (state.phase !== "end") return state;
      return { ...initialGameState(state.setup), phase: "rules", lastActionAt: action.at };
    case "newGame":
      // The setup's buttons can sit where this one was: keep the time so they are guarded too.
      return { ...initialGameState(state.setup), lastActionAt: action.at };
  }
  if (state.phase === "deal") return dealStep(state, action);
  return state;
}
```

```ts
type PickKind = "victim" | "seer" | "doctor" | "guess" | "poison";

function witchTurn(state: GameState): boolean {
  const { night } = state;
  const seat = state.roles.indexOf("witch");
  if (state.phase !== "night" || !night || seat < 0 || !state.alive[seat]) return false;
  return night.lap === "witch" && night.stage === "choose" && night.order[night.visit] === seat;
}

// What a tap on a player means right now, and whose choice it is.
function picker(state: GameState): { kind: PickKind; seat: number } | null {
  const { night } = state;
  if (state.phase !== "night" || !night) return null;
  if (witchTurn(state)) return state.potions.poison ? { kind: "poison", seat: state.roles.indexOf("witch") } : null;
  if (night.stage !== "choose" || night.lap !== "main") return null;
  const seat = night.order[night.visit];
  const role = state.roles[seat];
  if (role === "wolf") return { kind: "victim", seat };
  if (role === "seer" || role === "doctor") return { kind: role, seat };
  return { kind: "guess", seat };
}

export function canPick(state: GameState, target: number): boolean {
  const p = picker(state);
  if (!p || !state.alive[target]) return false;
  if (p.kind === "victim") return state.roles[target] !== "wolf";
  if (p.kind === "doctor") return target !== state.lastProtected;
  // The seer's first pick stands when the phone goes round, so one visit cannot test two players.
  if (p.kind === "seer" && state.setup.night === "pass" && state.night!.picks[p.seat] !== null) return false;
  return target !== p.seat;
}

export function canHeal(state: GameState): boolean {
  return witchTurn(state) && state.potions.heal && state.night!.victim !== null;
}

/** Whether Next may move the night on. */
export function canGoOn(state: GameState): boolean {
  const { night } = state;
  if (state.phase !== "night" || !night) return false;
  if (night.stage === "card") return state.revealed;
  return night.lap === "witch" || night.picks[night.order[night.visit]] !== null;
}

/** What the visitor holding the phone does tonight (Pass the phone only). */
export function visitTask(state: GameState): VisitTask | null {
  const { night } = state;
  if (state.phase !== "night" || !night || state.setup.night !== "pass") return null;
  const role = state.roles[night.order[night.visit]];
  if (night.lap === "witch") return role === "witch" ? "witch" : "idle";
  if (role === "wolf" || role === "seer" || role === "doctor") return role;
  return "guess";
}

/** The picks of the wolves who held the phone earlier this night, in visiting order. */

  const { night } = state;
  if (!night) return [];
  return night.order.slice(0, night.visit).flatMap((seat) => {
    const target = night.picks[seat];
    return state.roles[seat] === "wolf" && target !== null ? [{ wolf: seat, target }] : [];
  });
}

export function livingSeats(state: GameState): number[] {
  return state.alive.flatMap((alive, seat) => (alive ? [seat] : []));
}

export function pickOptions(state: GameState): { seat: number; enabled: boolean }[] {

// What the held card says: the dealt role, or tonight's task on a visit. Every card has the
// same parts, so no role looks different from across the table.
export function cardText(state: GameState, t: Strings): CardText | null {
  const names = state.setup.players;
  if (state.phase === "deal" && state.turn < names.length) {
    const role = state.roles[state.turn];
    const lines = [t[ROLE_DESC_KEYS[role]]];
    if (role === "wolf") {
      const others = otherWolves(state.roles, state.turn).map((seat) => names[seat]);
      lines.push(others.length > 0 ? t.wolfOtherWolves.replace("{names}", () => others.join(", ")) : t.wolfOnlyWolf);
    }
    return { heading: t.wolfYourRole, role, lines };
  }
  const task = visitTask(state);
  const night = state.night;
  if (!task || !night) return null;
  const role = state.roles[night.order[night.visit]];
  const heading = t.wolfNightN.replace("{n}", String(night.number));
  switch (task) {
    case "wolf": {
      const picks = wolfPicksSoFar(state).map(({ wolf, target }) => `${names[wolf]} → ${names[target]}`);
      const sofar = picks.length > 0 ? [t.wolfPicksSoFar.replace("{picks}", () => picks.join(", "))] : [];
      return { heading, role, lines: [t.wolfTaskWolf, ...sofar] };
    }
    case "seer":
      return { heading, role, lines: [t.wolfTaskSeer] };
    case "doctor":
      return { heading, role, lines: [t.wolfTaskDoctor] };
    case "guess":
      return { heading, role, lines: [t.wolfTaskGuess] };
    case "idle":
      return { heading, role, lines: [t.wolfNothingThisLap] };
    case "witch": {
      const left = [state.potions.heal ? t.wolfPotionHeal : "", state.potions.poison ? t.wolfPotionPoison : ""].filter(Boolean);
      const victim = night.victim === null ? [] : [t.wolfTaskWitch.replace("{name}", () => names[night.victim!])];
      return { heading, role, lines: [...victim, t.wolfPotionsLeft.replace("{list}", () => left.join(", "))] };
    }

/** The line under the choice once the visitor has picked: the seer's answer, or the pick. */
export function visitResult(state: GameState, t: Strings): string | null {
  const task = visitTask(state);
  const night = state.night;
  if (!task || !night || night.lap !== "main") return null;
  const pick = night.picks[night.order[night.visit]];
  if (pick === null) return null;
  const name = state.setup.players[pick];
  if (task === "seer") return `${name}: ${state.roles[pick] === "wolf" ? t.wolfIsWolf : t.wolfNotWolf}`;
  return t.wolfChosen.replace("{name}", () => name);
}

function removalOf(roles: Role[], alive: boolean[], removed: number[]): Removal {
  const hunter = removed.find((seat) => roles[seat] === "hunter");
  // With no wolf left the village has won whomever the hunter takes: no shot is asked for.
  const matters = alive.some((a, seat) => a && roles[seat] === "wolf");
  return { removed, hunter: hunter !== undefined && matters ? hunter : null, shot: null };
}

function toMorning(state: GameState, at: number): GameState {
  const night = state.night!;
  const removed = nightRemovals(night);
  const alive = state.alive.map((a, seat) => a && !removed.includes(seat));
  return {
    ...state,
    phase: "morning",
    alive,
    potions: { heal: state.potions.heal && !night.heal, poison: state.potions.poison && night.poison === null },
    lastProtected: night.protect,
    removal: removalOf(state.roles, alive, removed),
    revealed: false,
    lastActionAt: at,
  };
}

function witchMayAct(state: GameState): boolean {
  const seat = state.roles.indexOf("witch");
  return seat >= 0 && state.alive[seat] && (state.potions.heal || state.potions.poison);
}

function nightNext(state: GameState, rng: Rng, at: number): GameState {
  if (!canGoOn(state)) return state;
  const night = state.night!;
  const seat = night.order[night.visit];
  // On the witch lap only the witch has a choice; everyone else passes the phone on from the card.
  if (night.stage === "card" && (night.lap === "main" || state.roles[seat] === "witch")) {
    return { ...state, night: { ...night, stage: "choose" }, lastActionAt: at };
  }
  if (night.visit + 1 < night.order.length) {
    return { ...state, night: { ...night, visit: night.visit + 1, stage: "card" }, revealed: false, lastActionAt: at };
  }
  if (night.lap === "witch") return toMorning(state, at);
  const decided = { ...state, night: { ...night, victim: wolvesVictim(night.picks, state.roles, rng) } };
  if (!witchMayAct(state)) return toMorning(decided, at);
  return {
    ...decided,
    night: { ...decided.night, lap: "witch", visit: 0, stage: "card" },
    revealed: false,
    lastActionAt: at,
  };
}

function nightStep(state: GameState, action: GameAction): GameState {
  const night = state.night;
  if (!night) return state;
  switch (action.type) {
    case "reveal":
      if (state.setup.night !== "pass" || night.stage !== "card" || state.revealed) return state;
      return { ...state, revealed: true, lastActionAt: action.at };
    case "choose": {
      if (!canPick(state, action.target)) return state;
      const { kind, seat } = picker(state)!;
      const target = action.target;
      // A pick moves no turn on, so it does not restart the tap guard: Next right after it counts.
      if (kind === "poison") return { ...state, night: { ...night, poison: night.poison === target ? null : target } };
      const patch: Partial<Night> = {};
      if (state.setup.night === "pass") patch.picks = night.picks.map((p, i) => (i === seat ? target : p));
      else if (kind === "victim") patch.victim = target;
      if (kind === "seer") patch.seen = target;
      if (kind === "doctor") patch.protect = target;
      return { ...state, night: { ...night, ...patch } };
    }
    case "heal":
      if (!canHeal(state)) return state;
      return { ...state, night: { ...night, heal: !night.heal } };
    case "next":
      return nightNext(state, action.rng, action.at);
  }
  return state;
}
```

```tsx
"use client";

import { useLang } from "@/lib/i18n";
import {
  ROLE_DESC_KEYS,
  ROLE_NAME_KEYS,
  SPECIAL_ROLES,

  roleSummary,
  suggestWolves,

const stepper =
  "h-10 w-10 rounded-full border border-gray-200 text-xl font-bold text-gray-900 hover:bg-gray-100 disabled:opacity-40";

export default function WolfRolesStep({
  value,
  onChange,
}: {
  value: WolfSetup;
  onChange: (next: WolfSetup) => void;
}) {
  const { t } = useLang();
  const wolves = wolfCount(value);
  const suggested = suggestWolves(value.players.length);
  const max = maxWolves(value.players.length);
  // A count set by hand no longer follows the player count.
  const setWolves = (next: number) => onChange({ ...value, wolves: next });
  const toggle = (role: SpecialRole, on: boolean) =>
    onChange({ ...value, specials: SPECIAL_ROLES.filter((r) => (r === role ? on : value.specials.includes(r))) });

  return (
    <div className="space-y-5">
      <section className="space-y-2">
        <h3 className="text-sm font-medium text-gray-500">{t.wolfWolves}</h3>
        <div className="flex items-center gap-4">
          <button
            type="button"
            aria-label={t.wolfFewer}
            disabled={wolves <= 1}
            onClick={() => setWolves(wolves - 1)}
            className={stepper}
          >
            −
          </button>
          <span className="w-8 text-center text-2xl font-bold text-gray-900" aria-live="polite">
            {wolves}
          </span>
          <button
            type="button"
            aria-label={t.wolfMore}
            disabled={wolves >= max}
            onClick={() => setWolves(wolves + 1)}
            className={stepper}
          >
            +
          </button>
          <span className={`text-sm ${wolves === suggested ? "font-semibold text-gray-900" : "text-gray-500"}`}>
            {t.wolfSuggested.replace("{n}", String(suggested))}
          </span>
        </div>
      </section>

      <section className="space-y-3 rounded-xl border border-gray-100 bg-surface p-4">
        {SPECIAL_ROLES.map((role) => (
          <label key={role} className="flex items-center justify-between gap-3">
            <span>
              <span className="block text-gray-900">{t[ROLE_NAME_KEYS[role]]}</span>
              <span className="block text-xs text-gray-400">{t[ROLE_DESC_KEYS[role]]}</span>

          </label>
```

```tsx
"use client";

import { useLang } from "@/lib/i18n";
import {
  GAME_THEME,
  SETUP_ERROR_KEYS,
  SETUP_STEPS,
  playerColor,
  stepErrors,
  validateSetup,
  type WolfSetup,
} from "@/lib/wolf-game";
import SetupPlayersStep from "../SetupPlayersStep";
import WolfRolesStep from "./WolfRolesStep";
import WolfRulesStep from "./WolfRulesStep";

// The setup, one step at a time, like Imposter's. The step lives in the parent.
export default function WolfSetupWizard({
  value,
  onChange,
  step,
  onStep,
  onStart,
  quickStart,
}: {
  value: WolfSetup;
  onChange: (next: WolfSetup) => void;
  /** Index into SETUP_STEPS. */
  step: number;
  onStep: (step: number) => void;
  onStart: () => void;
  /** A game was played on this device before: offer to skip the remaining steps. */
  quickStart: boolean;
}) {
  const { t } = useLang();
  const name = SETUP_STEPS[step];
  const last = step === SETUP_STEPS.length - 1;
  const allErrors = validateSetup(value);
  // The last step shows everything that still blocks Start, whichever step it belongs to.
  const errors = last ? allErrors : stepErrors(value, name);
  const titles = { players: t.imposterPlayers, roles: t.wolfStepRoles, rules: t.imposterStepRules };
  const primary = "flex-1 rounded-lg bg-blue-600 py-3 font-semibold text-white hover:bg-blue-700 disabled:opacity-50";

  return (
    <div className="space-y-5">
      <div className="flex items-center justify-between">
        <h2 className="text-lg font-bold text-gray-900">{titles[name]}</h2>
        <div
          className="flex gap-1.5"
          role="img"
          aria-label={t.imposterStep.replace("{n}", String(step + 1)).replace("{total}", String(SETUP_STEPS.length))}
        >
          {SETUP_STEPS.map((s, i) => (
            <span key={s} className={`h-2 w-2 rounded-full ${i === step ? "bg-white" : "bg-white/30"}`} />
          ))}
        </div>
      </div>

      {name === "players" && <SetupPlayersStep value={value} onChange={onChange} />}
      {name === "roles" && <WolfRolesStep value={value} onChange={onChange} />}
      {name === "rules" && <WolfRulesStep value={value} onChange={onChange} />}

      {errors.length > 0 && (
        <ul role="alert" className="space-y-1 rounded-lg bg-amber-50 p-3 text-sm text-amber-700 dark:text-amber-400">
          {errors.map((e) => (
            <li key={e}>{t[SETUP_ERROR_KEYS[e]]}</li>
          ))}
        </ul>
      )}

      <div className="flex gap-3">
        {step > 0 && (
          <button
            type="button"
            onClick={() => onStep(step - 1)}
            className="flex-1 rounded-lg border border-gray-200 py-3 text-gray-600 hover:bg-gray-100"
          >
            {t.back}
          </button>
        )}
        {last ? (
          <button type="button" disabled={allErrors.length > 0} onClick={onStart} className={primary}>
            {t.imposterStart}
          </button>
        ) : (
          <button type="button" disabled={errors.length > 0} onClick={() => onStep(step + 1)} className={primary}>
            {t.imposterNext}
          </button>
        )}
      </div>

      {step === 0 && quickStart && allErrors.length === 0 && (
        <button
          type="button"
          onClick={onStart}
          className="w-full rounded-lg py-3 font-semibold"
          style={{ backgroundColor: playerColor(2), color: GAME_THEME.ink }}
        >
          {t.imposterQuickStart}
        </button>
      )}
    </div>
  );
}
```

```tsx
  setup,
  onDeal,
  onBack,
  onClose,
```

```tsx
"use client";

import { GAME_THEME, playerColor } from "@/lib/wolf-game";

export interface PickOption {
  seat: number;
  enabled: boolean;
}

// One button per player, in that player's colour. A check mark, not only the border, shows
// the pick.
export default function WolfPicker({
  options,
  names,
  selected,
  onPick,
  note,
}: {
  options: PickOption[];
  names: string[];
  selected: number | null;
  onPick: (seat: number) => void;
  /** A second line under the name, e.g. the role on the narrator's screen. */
  note?: (seat: number) => string;
}) {
  return (
    <div className="grid grid-cols-2 gap-2">
      {options.map(({ seat, enabled }) => {
        const chosen = selected === seat;
        return (
          <button
            key={seat}
            type="button"
            disabled={!enabled}
            aria-pressed={chosen}
            onClick={() => onPick(seat)}
            className={`rounded-xl py-3 font-semibold disabled:opacity-40 ${chosen ? "border-4" : "border-2"}`}
            style={{
              backgroundColor: playerColor(seat),
              color: GAME_THEME.ink,
              borderColor: chosen ? GAME_THEME.text : GAME_THEME.bg,
            }}
          >
            {chosen ? "✓ " : ""}
            {names[seat]}
            {note && <span className="block text-xs font-normal">{note(seat)}</span>}
          </button>
        );
      })}
    </div>
  );
}
```

```tsx
import { useLang } from "@/lib/i18n";
import { canHeal, pickOptions, type GameState } from "@/lib/wolf-game";
import WolfPicker from "./WolfPicker";

// The witch's choices, on her visit and on the narrator's witch line. Text takes the colour of
// the screen it is on.
export default function WolfWitch({
  state,
  onHeal,
  onPick,
  note,
}: {
  state: GameState;
  onHeal: () => void;
  onPick: (seat: number) => void;
  note?: (seat: number) => string;
}) {
  const { t } = useLang();
  const night = state.night;
  if (!night) return null;
  const names = state.setup.players;
  const victim = night.victim;
  const { heal, poison } = state.potions;

  return (
    <div className="space-y-4">
      {victim !== null && <p className="text-lg font-semibold">{t.wolfTaskWitch.replace("{name}", () => names[victim])}</p>}
      {!heal && !poison && <p>{t.wolfNoPotions}</p>}
      {victim !== null && canHeal(state) && (
        <button
          type="button"
          aria-pressed={night.heal}
          onClick={onHeal}
          className={`w-full rounded-xl border-current py-3 font-semibold ${night.heal ? "border-4" : "border-2"}`}
        >
          {night.heal ? "✓ " : ""}
          {t.wolfHeal.replace("{name}", () => names[victim])}
        </button>
      )}
      {poison && (
        <div className="space-y-2">
          <p className="font-semibold">{t.wolfPoison}</p>
          <WolfPicker options={pickOptions(state)} names={names} selected={night.poison} onPick={onPick} note={note} />

    </div>
  );
```

```tsx
import { useLang } from "@/lib/i18n";
```

```tsx
// The day: the table talks (with the optional timer), then the phone holder enters the vote.
// The timer counts to the day's end time in the game state, so leaving for the rules does
// not restart it.
export default function WolfDay({
  state,
  onVote,
  onTalk,
  onVoteOut,
  onRules,
}: {
  state: GameState;
  onVote: () => void;
  onTalk: () => void;
  onVoteOut: (seat: number | null) => void;
  onRules: () => void;
}) {
  const { t } = useLang();
  const [now, setNow] = useState(() => Date.now());
  const ticking = state.setup.timerMinutes > 0 && state.dayStep === "talk";

  useEffect(() => {
    if (!ticking) return;
    const id = setInterval(() => setNow(Date.now()), 250);
    return () => clearInterval(id);
  }, [ticking]);

  const names = state.setup.players;
  const living = livingSeats(state);
  const chip = (seat: number) => ({ backgroundColor: playerColor(seat), color: GAME_THEME.ink });

          {t.back}
        </button>
      </div>
    );
```

```tsx
"use client";

import { useEffect, useReducer, useState } from "react";
import { useLang } from "@/lib/i18n";
import {
  DEFAULT_SETUP,
  NARRATOR_COLOR,
  SETUP_STORAGE_KEY,
  gameReducer,
  initialGameState,
  parseSavedSetup,
  playerColor,
  validateSetup,
  type WolfSetup,
} from "@/lib/wolf-game";
import DealTurn from "../DealTurn";
import GameFrame from "../GameFrame";
import PassPhone from "../PassPhone";
import WolfCard from "./WolfCard";
import WolfChoose from "./WolfChoose";
import WolfDay from "./WolfDay";
import WolfEnd from "./WolfEnd";
import WolfNarrator from "./WolfNarrator";
import WolfRemoval from "./WolfRemoval";
import WolfRoster from "./WolfRoster";
import WolfRulesButton from "./WolfRulesButton";
import WolfSetupWizard from "./WolfSetupWizard";
import WolfThisGame from "./WolfThisGame";

function loadSetup(): WolfSetup {
  try {
    return parseSavedSetup(localStorage.getItem(SETUP_STORAGE_KEY));
  } catch {
    return DEFAULT_SETUP;
  }
}

function saveSetup(setup: WolfSetup) {
  try {
    localStorage.setItem(SETUP_STORAGE_KEY, JSON.stringify(setup));
  } catch {
    // Private mode or full storage: the game still runs, the names just are not remembered.
  }
}

// Returns only other components, never a host element: its test renders it without a DOM.
export default function WolfGame() {
  const { t } = useLang();
  const [state, dispatch] = useReducer(gameReducer, undefined, () => initialGameState());
  const [draft, setDraft] = useState<WolfSetup>(DEFAULT_SETUP);
  const [step, setStep] = useState(0);
  // A game was played on this device before: the wizard may offer to skip its steps.
  const [played, setPlayed] = useState(false);
  // The This game screen opened from a Rules button covers the game until it is closed.
  const [rulesOpen, setRulesOpen] = useState(false);

  // Read after mount: localStorage does not exist during prerendering.
  useEffect(() => {
    const saved = loadSetup();
    // eslint-disable-next-line react-hooks/set-state-in-effect
    setDraft(saved);
    setPlayed(validateSetup(saved).length === 0);
  }, []);

  const { phase, setup, night } = state;
  const names = setup.players;
  const reveal = () => dispatch({ type: "reveal", at: Date.now() });
  const next = () => dispatch({ type: "next", rng: Math.random, at: Date.now() });
  const pick = (target: number) => dispatch({ type: "choose", target, at: Date.now() });
  const heal = () => dispatch({ type: "heal", at: Date.now() });
  const openRules = () => setRulesOpen(true);
  const newGame = () => {
    setDraft(setup);
    dispatch({ type: "newGame", at: Date.now() });
  };

  if (phase === "setup") {
    return (
      <GameFrame>
        <WolfSetupWizard
          value={draft}
          onChange={setDraft}
          step={step}
          onStep={setStep}
          quickStart={played}
          onStart={() => {
            saveSetup(draft);
            setPlayed(true);
            setStep(0);
            dispatch({ type: "start", setup: draft, at: Date.now() });
          }}
        />
      </GameFrame>
    );
  }

  if (phase === "rules") {
    return (
      <GameFrame>
        <WolfThisGame
          setup={setup}
          onDeal={() => dispatch({ type: "deal", rng: Math.random, at: Date.now() })}
          onBack={newGame}
        />
      </GameFrame>
    );
  }

  if (rulesOpen) {
    return (
      <GameFrame>
        <WolfThisGame setup={setup} onClose={() => setRulesOpen(false)} />
      </GameFrame>
    );
  }

  if (phase === "deal" && state.turn === names.length) {
    return (
      <GameFrame color={NARRATOR_COLOR}>
        <PassPhone name={t.wolfTheNarrator} revealed={state.revealed} revealLabel={t.wolfShowAllRoles} onReveal={reveal}>
          <WolfRoster state={state} onStart={next} />
        </PassPhone>
      </GameFrame>
    );
  }

  if (phase === "deal") {
    return (
      <GameFrame color={playerColor(state.turn)}>
        <WolfRulesButton onClick={openRules} />
        <DealTurn key={`deal-${state.turn}`} name={names[state.turn]} revealed={state.revealed} onReveal={reveal} onNext={next}>
          <WolfCard state={state} />
        </DealTurn>
      </GameFrame>
    );
  }

  if (phase === "night" && night && setup.night === "narrator") {
    return (
      <GameFrame>
        <WolfNarrator state={state} onPick={pick} onHeal={heal} onNext={next} onRules={openRules} />
      </GameFrame>
    );
  }

  if (phase === "night" && night) {
    const seat = night.order[night.visit];
    if (night.stage === "card") {
      return (
        <GameFrame color={playerColor(seat)}>
          <WolfRulesButton onClick={openRules} />
          <DealTurn
            key={`night-${night.number}-${night.lap}-${seat}`}
            name={names[seat]}
            revealed={state.revealed}
            onReveal={reveal}
            onNext={next}
            nextLabel={t.wolfContinue}
          >
            <WolfCard state={state} />
          </DealTurn>
        </GameFrame>
      );
    }
    return (
      <GameFrame color={playerColor(seat)}>
        <WolfChoose state={state} onPick={pick} onHeal={heal} onNext={next} />
      </GameFrame>
    );
  }

  if (phase === "morning" || (phase === "day" && state.dayStep === "result")) {
    return (
      <GameFrame>
        <WolfRemoval
          state={state}
          onShoot={(target) => dispatch({ type: "shoot", target, at: Date.now() })}
          onContinue={() => dispatch({ type: "continue", at: Date.now() })}
          onRules={phase === "morning" ? openRules : undefined}
        />
      </GameFrame>
    );
  }

  if (phase === "day") {
    return (
      <GameFrame>
        <WolfDay
          state={state}
          onVote={() => dispatch({ type: "vote", at: Date.now() })}
          onTalk={() => dispatch({ type: "talk", at: Date.now() })}
          onVoteOut={(target) => dispatch({ type: "voteOut", target, at: Date.now() })}
          onRules={openRules}
        />
      </GameFrame>
    );
  }

  return (
    <GameFrame>
      <WolfEnd state={state} onPlayAgain={() => dispatch({ type: "playAgain", at: Date.now() })} onNewGame={newGame} />
    </GameFrame>
  );
}
```

```tsx
import { Pressable, Switch, Text, View } from "react-native";

import { useLang } from "@ptracker/shared/i18n";
import {
  ROLE_DESC_KEYS,
  ROLE_NAME_KEYS,
  SPECIAL_ROLES,
  maxWolves,
  roleSummary,
  suggestWolves,
  wolfCount,
  type SpecialRole,
  type WolfSetup,
} from "@ptracker/shared/wolf-game";

export function WolfRolesStep({ value, onChange }: { value: WolfSetup; onChange: (next: WolfSetup) => void }) {
  const { t } = useLang();
  const wolves = wolfCount(value);
  const suggested = suggestWolves(value.players.length);
  const max = maxWolves(value.players.length);
  // A count set by hand no longer follows the player count.
  const setWolves = (next: number) => onChange({ ...value, wolves: next });
  const toggle = (role: SpecialRole, on: boolean) =>
    onChange({ ...value, specials: SPECIAL_ROLES.filter((r) => (r === role ? on : value.specials.includes(r))) });
  const stepper = (label: string, sign: string, disabled: boolean, onPress: () => void) => (
    <Pressable
      accessibilityRole="button"
      accessibilityLabel={label}
      accessibilityState={{ disabled }}
      disabled={disabled}
      onPress={onPress}
      className={`h-11 w-11 items-center justify-center rounded-full border border-gray-200 ${disabled ? "opacity-40" : ""}`}>
      <Text className="text-xl font-bold text-gray-900">{sign}</Text>
    </Pressable>
  );

  return (
    <View className="gap-5">
      <View className="gap-2">
        <Text className="text-sm font-medium text-gray-500">{t.wolfWolves}</Text>
        <View className="flex-row items-center gap-4">
          {stepper(t.wolfFewer, "−", wolves <= 1, () => setWolves(wolves - 1))}
          <Text className="w-8 text-center text-2xl font-bold text-gray-900" accessibilityLiveRegion="polite">
            {wolves}
          </Text>
          {stepper(t.wolfMore, "+", wolves >= max, () => setWolves(wolves + 1))}
          <Text className={`text-sm ${wolves === suggested ? "font-semibold text-gray-900" : "text-gray-500"}`}>
            {t.wolfSuggested.replace("{n}", String(suggested))}
          </Text>
        </View>
      </View>

      <View className="gap-3 rounded-xl border border-gray-100 p-4">
        {SPECIAL_ROLES.map((role) => (
          <View key={role} className="flex-row items-center justify-between gap-3">
            <View className="flex-1">
              <Text className="text-base text-gray-900">{t[ROLE_NAME_KEYS[role]]}</Text>
              <Text className="text-xs text-gray-400">{t[ROLE_DESC_KEYS[role]]}</Text>
            </View>
            <Switch
              accessibilityLabel={t[ROLE_NAME_KEYS[role]]}
              value={value.specials.includes(role)}
              onValueChange={(on) => toggle(role, on)}
            />
          </View>
        ))}
      </View>

      <Text className="text-center text-base font-semibold text-gray-900">{roleSummary(value, t)}</Text>

  );
```

```tsx
import { Pressable, Text, View } from "react-native";

import { useLang } from "@ptracker/shared/i18n";
import {

  SETUP_ERROR_KEYS,
  SETUP_STEPS,
  playerColor,
  stepErrors,
  validateSetup,
  type WolfSetup,

import { WolfRolesStep } from "@/components/games/wolf/wolf-roles-step";
import { WolfRulesStep } from "@/components/games/wolf/wolf-rules-step";
import { PrimaryButton } from "@/components/ui/primary-button";

// The setup, one step at a time, like Imposter's. The step lives in the parent.
export function WolfSetupWizard({
  value,
  onChange,
  step,
  onStep,
  onStart,
  quickStart,
}: {
  value: WolfSetup;
  onChange: (next: WolfSetup) => void;
  /** Index into SETUP_STEPS. */
  step: number;
  onStep: (step: number) => void;
  onStart: () => void;
  /** A game was played on this device before: offer to skip the remaining steps. */
  quickStart: boolean;
}) {
  const { t } = useLang();
  const name = SETUP_STEPS[step];
  const last = step === SETUP_STEPS.length - 1;
  const allErrors = validateSetup(value);
  // The last step shows everything that still blocks Start, whichever step it belongs to.
  const errors = last ? allErrors : stepErrors(value, name);
  const titles = { players: t.imposterPlayers, roles: t.wolfStepRoles, rules: t.imposterStepRules };

  return (
    <View className="gap-5">
      <View className="flex-row items-center justify-between">
        <Text className="text-xl font-bold text-gray-900">{titles[name]}</Text>
        <View
          className="flex-row gap-1.5"
          accessible
          accessibilityLabel={t.imposterStep.replace("{n}", String(step + 1)).replace("{total}", String(SETUP_STEPS.length))}>
          {SETUP_STEPS.map((s, i) => (
            <View
              key={s}
              className="h-2 w-2 rounded-full"
              style={{ backgroundColor: GAME_THEME.text, opacity: i === step ? 1 : 0.3 }}
            />
          ))}
        </View>
      </View>

      {name === "players" ? <SetupPlayersStep value={value} onChange={onChange} /> : null}
      {name === "roles" ? <WolfRolesStep value={value} onChange={onChange} /> : null}
      {name === "rules" ? <WolfRulesStep value={value} onChange={onChange} /> : null}

      {errors.length > 0 ? (
        <View className="gap-1 rounded-lg bg-amber-50 p-3" accessibilityRole="alert" accessibilityLiveRegion="polite">
          {errors.map((e) => (
            <Text key={e} className="text-sm text-amber-700">
              {t[SETUP_ERROR_KEYS[e]]}
            </Text>
          ))}
        </View>
      ) : null}

      <View className="flex-row items-center gap-3">
        {step > 0 ? (
          <Pressable
            accessibilityRole="button"
            onPress={() => onStep(step - 1)}
            className="flex-1 rounded-lg border border-gray-200 py-3">
            <Text className="text-center text-base text-gray-600">{t.back}</Text>
          </Pressable>
        ) : null}
        <View className="flex-1">
          {last ? (
            <PrimaryButton label={t.imposterStart} onPress={onStart} disabled={allErrors.length > 0} />
          ) : (
            <PrimaryButton label={t.imposterNext} onPress={() => onStep(step + 1)} disabled={errors.length > 0} />
          )}
        </View>
      </View>

      {step === 0 && quickStart && allErrors.length === 0 ? (
        <Pressable
          accessibilityRole="button"
          onPress={onStart}
          className="rounded-lg py-3.5"
          style={{ backgroundColor: playerColor(2) }}>
          <Text className="text-center text-base font-semibold" style={{ color: GAME_THEME.ink }}>
            {t.imposterQuickStart}
          </Text>
        </Pressable>
      ) : null}
    </View>
  );
}
```

```tsx
  options,
  names,
  selected,
  onPick,
  note,
}: {
  options: PickOption[];
  names: string[];
  selected: number | null;
  onPick: (seat: number) => void;

            key={seat}
            accessibilityRole="button"
            accessibilityState={{ disabled: !enabled, selected: chosen }}
            disabled={!enabled}
```

```tsx
import { GAME_THEME, canHeal, pickOptions, type GameState } from "@ptracker/shared/wolf-game";
import { WolfPicker } from "@/components/games/wolf/wolf-picker";

// The witch's choices, on her visit (`ink`: on her colour) and on the narrator's witch line.
export function WolfWitch({
  state,
  onHeal,
  onPick,
  note,
  ink = false,
}: {
  state: GameState;
  onHeal: () => void;
  onPick: (seat: number) => void;

  const color = ink ? { color: GAME_THEME.ink } : undefined;

    <View className="gap-4">

          {t.wolfNoPotions}
        </Text>
      ) : null}

          accessibilityRole="button"

          </Text>
          <WolfPicker options={pickOptions(state)} names={names} selected={night.poison} onPick={onPick} note={note} />
        </View>
      ) : null}
    </View>
  );
}
```

```tsx
import { Text, View } from "react-native";

import { useLang } from "@ptracker/shared/i18n";
import {
  NARRATOR_LINE_KEYS,
  ROLE_NAME_KEYS,
  canGoOn,
  lineRemoved,
  narratorLine,
  pickOptions,
  type GameState,
} from "@ptracker/shared/wolf-game";
import { WolfPicker } from "@/components/games/wolf/wolf-picker";
import { WolfRulesButton } from "@/components/games/wolf/wolf-rules-button";
import { WolfWitch } from "@/components/games/wolf/wolf-witch";

// The narrator's night, one line at a time. The narrator does not play, so the player
// buttons show every role.
export function WolfNarrator({
  state,
  onPick,
  onHeal,
  onNext,
  onRules,
}: {
  state: GameState;
  onPick: (seat: number) => void;
  onHeal: () => void;
  onNext: () => void;
  onRules: () => void;
}) {
  const { t } = useLang();
  const night = state.night;
  const line = narratorLine(state);
  if (!night || !line) return null;
  const names = state.setup.players;
  const removed = lineRemoved(state);
  const role = (seat: number) => t[ROLE_NAME_KEYS[state.roles[seat]]];
  const picker = (selected: number | null) => (
    <WolfPicker options={pickOptions(state)} names={names} selected={selected} onPick={onPick} note={role} />
  );
  const nothing = line === "witch" && !removed && !night.heal && night.poison === null;

  return (
    <View className="gap-5">
      <WolfRulesButton onPress={onRules} />
      <Text className="text-center text-sm text-gray-500">{t.wolfNightN.replace("{n}", String(night.number))}</Text>

      {removed ? <Text className="text-center text-base text-gray-500">{t.wolfLineRemoved}</Text> : null}
      {line === "wolves" ? picker(night.victim) : null}
      {line === "seer" && !removed ? (
        <>
          {picker(night.seen)}
          {night.seen !== null ? (
            <Text className="text-center text-3xl font-bold text-gray-900" accessibilityLiveRegion="polite">

      ) : null}

      {line === "witch" && !removed ? <WolfWitch state={state} onHeal={onHeal} onPick={onPick} note={role} /> : null}
      <PrimaryButton label={nothing ? t.wolfNothing : t.wolfNext} onPress={onNext} disabled={!canGoOn(state)} />
    </View>
  );
}
```

```tsx
// The day: the table talks (with the optional timer), then the phone holder enters the vote.
// The timer counts to the day's end time in the game state, so leaving for the rules does not
// restart it. It does not buzz: the game has no sound or vibration.
export function WolfDay({
  state,
  onVote,
  onTalk,
  onVoteOut,
  onRules,
}: {
  state: GameState;
  onVote: () => void;
  onTalk: () => void;
  onVoteOut: (seat: number | null) => void;
  onRules: () => void;
}) {
  const { t } = useLang();
  const [now, setNow] = useState(() => Date.now());
  const ticking = state.setup.timerMinutes > 0 && state.dayStep === "talk";

  useEffect(() => {
    if (!ticking) return;
    const id = setInterval(() => setNow(Date.now()), 250);
    return () => clearInterval(id);
  }, [ticking]);

  const names = state.setup.players;
  const living = livingSeats(state);
  const ink = { color: GAME_THEME.ink };

  if (state.dayStep === "vote") {
    return (
      <View className="gap-5">
        <Text className="text-center text-xl font-bold text-gray-900">{t.wolfVoteQuestion}</Text>
        <WolfPicker
          options={living.map((seat) => ({ seat, enabled: true }))}
          names={names}
          selected={null}
          onPick={onVoteOut}
        />
        <Pressable
          accessibilityRole="button"
          onPress={() => onVoteOut(null)}
          className="rounded-xl border-2 border-gray-200 py-3">
          <Text className="text-center text-base font-semibold text-gray-900">{t.wolfNobody}</Text>
        </Pressable>
        <Pressable accessibilityRole="button" onPress={onTalk} className="py-2">
          <Text className="text-center text-sm text-gray-500">{t.back}</Text>
        </Pressable>
      </View>
    );
  }

  const left = remainingSeconds(state.dayEndsAt, now);
  const out = names.flatMap((_, seat) => (state.alive[seat] ? [] : [seat]));

  return (
    <View className="gap-5">
      <WolfRulesButton onPress={onRules} />
      <Text className="text-center text-2xl font-bold text-gray-900">
        {t.wolfDayN.replace("{n}", String(state.night?.number ?? 1))}
      </Text>
      {state.setup.timerMinutes > 0 ? (
        <Text className={`text-center text-5xl font-semibold ${left === 0 ? "text-red-600" : "text-gray-900"}`}>
          {left === 0 ? t.imposterTimeUp : formatCountdown(left)}
        </Text>
      ) : null}
      <View className="gap-2">
        <Text className="text-sm font-medium text-gray-500">{t.wolfInGame}</Text>
        <View className="flex-row flex-wrap gap-2">

            <View key={seat} className="rounded-full px-3 py-1" style={{ backgroundColor: playerColor(seat) }}>
              <Text className="text-base font-semibold" style={ink}>
                {names[seat]}
              </Text>
            </View>
          ))}
        </View>
      </View>
      {out.length > 0 ? (
        <View className="gap-2">
          <Text className="text-sm font-medium text-gray-500">{t.wolfOut}</Text>

              </View>
            ))}
          </View>
        </View>
      ) : null}
      <PrimaryButton label={t.wolfVote} onPress={onVote} />
    </View>
  );
}
```

```ts
const find = (type: unknown) => nodes(render()).find((n) => n.type === type);
const has = (type: unknown) => find(type) !== undefined;
const call = (type: unknown, name: string, ...args: unknown[]) => (find(type)!.props[name] as (...a: unknown[]) => void)(...args);

async function load(setup: WolfSetup) {
  storage.getStoredWolfSetup.mockResolvedValue(setup);
  render();
  for (const effect of hooks.effects) effect();
  await Promise.resolve();
  await Promise.resolve();
}

async function start(setup: WolfSetup = valid) {
  await load(setup);
  call(WolfSetupWizard, "onStart");
}

function dealAll(count: number) {
  for (let i = 0; i < count; i++) {
    call(DealTurn, "onReveal");
    call(DealTurn, "onNext");
  }
}

// The phone goes round once: every visitor holds the card and picks the first player allowed.
function passNight() {
  for (let guard = 0; has(DealTurn) || has(WolfChoose); guard++) {
    if (guard > 30) throw new Error("the night did not end");
    if (has(DealTurn)) {
      call(DealTurn, "onReveal");
      call(DealTurn, "onNext");
    } else {
      const s = find(WolfChoose)!.props.state as GameState;
      call(WolfChoose, "onPick", s.alive.findIndex((_, i) => canPick(s, i)));
      call(WolfChoose, "onNext");
    }
  }
}
```

```tsx
import { useEffect, useReducer, useState } from "react";
import { ActivityIndicator } from "react-native";

import { useLang } from "@ptracker/shared/i18n";
import {
  NARRATOR_COLOR,
  gameReducer,
  initialGameState,
  playerColor,
  validateSetup,
  type WolfSetup,
} from "@ptracker/shared/wolf-game";
import { DealTurn } from "@/components/games/deal-turn";
import { GamesPinSetup, useEnterGameModeOnce } from "@/components/games/game-mode-entry";
import { GameScreen } from "@/components/games/game-screen";
import { PassPhone } from "@/components/games/pass-phone";
import { WolfCard } from "@/components/games/wolf/wolf-card";
import { WolfChoose } from "@/components/games/wolf/wolf-choose";
import { WolfDay } from "@/components/games/wolf/wolf-day";
import { WolfEnd } from "@/components/games/wolf/wolf-end";
import { WolfNarrator } from "@/components/games/wolf/wolf-narrator";
import { WolfRemoval } from "@/components/games/wolf/wolf-removal";
import { WolfRoster } from "@/components/games/wolf/wolf-roster";
import { WolfRulesButton } from "@/components/games/wolf/wolf-rules-button";
import { WolfSetupWizard } from "@/components/games/wolf/wolf-setup";
import { WolfThisGame } from "@/components/games/wolf/wolf-this-game";
import { getStoredWolfSetup, setStoredWolfSetup } from "@/lib/wolf-game-storage";

export default function WolfScreen() {
  const { t } = useLang();
  const [state, dispatch] = useReducer(gameReducer, undefined, () => initialGameState());
  const [draft, setDraft] = useState<WolfSetup | null>(null);
  const [step, setStep] = useState(0);
  // A game was played on this device before: the wizard may offer to skip its steps.
  const [played, setPlayed] = useState(false);
  // The This game screen opened from a Rules button covers the game until it is closed.
  const [rulesOpen, setRulesOpen] = useState(false);
  const pinReady = useEnterGameModeOnce();

  useEffect(() => {
    getStoredWolfSetup().then((saved) => {
      setDraft(saved);
      setPlayed(validateSetup(saved).length === 0);
    });
  }, []);

  if (!pinReady) return <GamesPinSetup title={t.wolfTitle} />;

  const { phase, setup, night } = state;
  const names = setup.players;
  const reveal = () => dispatch({ type: "reveal", at: Date.now() });
  const next = () => dispatch({ type: "next", rng: Math.random, at: Date.now() });
  const pick = (target: number) => dispatch({ type: "choose", target, at: Date.now() });
  const heal = () => dispatch({ type: "heal", at: Date.now() });
  const openRules = () => setRulesOpen(true);
  const newGame = () => {
    setDraft(setup);
    dispatch({ type: "newGame", at: Date.now() });
  };

  let body: React.ReactNode = null;
  // A screen that belongs to one player takes that player's colour.
  let color: string | undefined;
  // A held card must not sit in a ScrollView: the press is lost as soon as the finger drifts.
  let held = false;

  if (phase === "setup") {
    body = draft ? (
      <WolfSetupWizard
        value={draft}
        onChange={setDraft}
        step={step}
        onStep={setStep}
        quickStart={played}
        onStart={() => {
          void setStoredWolfSetup(draft);
          setPlayed(true);
          setStep(0);
          dispatch({ type: "start", setup: draft, at: Date.now() });
        }}
      />
    ) : (
      <ActivityIndicator />
    );
  } else if (phase === "rules") {
    body = (
      <WolfThisGame
        setup={setup}
        onDeal={() => dispatch({ type: "deal", rng: Math.random, at: Date.now() })}
        onBack={newGame}
      />
    );
  } else if (rulesOpen) {
    body = <WolfThisGame setup={setup} onClose={() => setRulesOpen(false)} />;
  } else if (phase === "deal" && state.turn === names.length) {
    color = NARRATOR_COLOR;
    body = (
      <PassPhone name={t.wolfTheNarrator} revealed={state.revealed} revealLabel={t.wolfShowAllRoles} onReveal={reveal}>
        <WolfRoster state={state} onStart={next} />
      </PassPhone>
    );
  } else if (phase === "deal") {
    color = playerColor(state.turn);
    held = true;
    body = (
      <>
        <WolfRulesButton onPress={openRules} ink />
        <DealTurn key={`deal-${state.turn}`} name={names[state.turn]} revealed={state.revealed} onReveal={reveal} onNext={next}>
          <WolfCard state={state} />
        </DealTurn>
      </>
    );
  } else if (phase === "night" && night && setup.night === "narrator") {
    body = <WolfNarrator state={state} onPick={pick} onHeal={heal} onNext={next} onRules={openRules} />;
  } else if (phase === "night" && night) {
    const seat = night.order[night.visit];
    color = playerColor(seat);
    if (night.stage === "card") {
      held = true;
      body = (
        <>
          <WolfRulesButton onPress={openRules} ink />
          <DealTurn
            key={`night-${night.number}-${night.lap}-${seat}`}
            name={names[seat]}
            revealed={state.revealed}
            onReveal={reveal}
            onNext={next}
            nextLabel={t.wolfContinue}>
            <WolfCard state={state} />
          </DealTurn>
        </>
      );
    } else {
      body = <WolfChoose state={state} onPick={pick} onHeal={heal} onNext={next} />;
    }
  } else if (phase === "morning" || (phase === "day" && state.dayStep === "result")) {
    body = (
      <WolfRemoval
        state={state}
        onShoot={(target) => dispatch({ type: "shoot", target, at: Date.now() })}
        onContinue={() => dispatch({ type: "continue", at: Date.now() })}
        onRules={phase === "morning" ? openRules : undefined}
      />
    );
  } else if (phase === "day") {
    body = (
      <WolfDay
        state={state}
        onVote={() => dispatch({ type: "vote", at: Date.now() })}
        onTalk={() => dispatch({ type: "talk", at: Date.now() })}
        onVoteOut={(target) => dispatch({ type: "voteOut", target, at: Date.now() })}
        onRules={openRules}
      />
    );
  } else {
    body = <WolfEnd state={state} onPlayAgain={() => dispatch({ type: "playAgain", at: Date.now() })} onNewGame={newGame} />;
  }

  return (
    <GameScreen title={t.wolfTitle} tone="game" color={color} scroll={!held}>
      {body}
    </GameScreen>
  );
}
```
