# Describe It (word game) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The "Describe It" / "Anlat Bul" team word game on web (`/games/word`) and mobile (`games/word`), playable offline, built on Imposter's frame, palette and screens.

**Architecture:** All rules live in `shared/word-game.ts` as plain TypeScript: setup defaults, validation and parsing, the deck builder and a pure reducer whose actions carry their tap time (`at`). The reducer never loads the word lists: `start` is handed the language's lists, the device's seen list and an `Rng`, so every test runs on small fixtures. Web and mobile only render the reducer's state and save the setup and the seen list (web `localStorage`, mobile `AsyncStorage`, both fail-soft).

**Tech Stack:** Next.js 16 (App Router, client components, Tailwind), Expo SDK 57 + Expo Router + NativeWind, vitest (node env), service worker Cache API.

**Spec:** `docs/superpowers/specs/2026-11-13-word-game-design.md`

**Branch / worktree:** `feature/word-game` in `.claude/worktrees/word-game`. The word lists (`shared/word-game-words/{tr,en}/*.ts`) and their test are written by other agents: never edit them.

**Ground rules for every task**
- `shared/` files contain no JSX. `shared/word-game.ts` imports only `./word-game-words/types`, never the lists' index.
- Every new string goes into BOTH `en` and `tr` in `shared/i18n.ts` (the parity test enforces it).
- Tests never load the real word lists: the reducer gets fixture lists, and screen tests mock `@/lib/word-game-words` / `@ptracker/shared/word-game-words`.
- Web page code follows `node_modules/next/dist/docs/01-app/01-getting-started/05-server-and-client-components.md` (client components with `"use client"`, as the Imposter page). Mobile uses only React Native core and libraries already installed (no native module: the app ships as an OTA update).
- No sound or vibration (out of scope in the spec).
- Commits: conventional commits, signed, staged by explicit path and committed with `git commit -m "…" -- <paths>` so files staged by other agents cannot ride along. Every file ends with a newline.

**Decisions the spec leaves open (closest to Imposter)**
- Default mode Free, default end By rounds (the first options listed); category and difficulty default to Mixed.
- "Time's up!" replaces the card for `WORD_TIME_UP_MS` (1.5 s) with the buttons disabled, then the turn ends; the summary's heading repeats it. The pause also keeps a late tap off the summary's buttons.
- When the deck runs out mid-turn the turn ends at once: its summary says "No words left" and Next goes to the end screen, which shows the note.
- The time-up word goes to the bottom of the deck. Scores may go below zero.
- Play again keeps the game's language and draws a new deck without the words already shown.
- The 50-word refill rule is applied literally: a single category at one level (35–60 words) is refilled at every game start.

import type { Lang } from "./i18n";
import { PLAYER_COLORS } from "./imposter";
import { WORD_CATEGORIES, type WordCategory } from "./word-game-words/types";

export { WORD_CATEGORIES };
export type { WordCard, WordCategory, WordLevel } from "./word-game-words/types";

export type Rng = () => number;
export type WordMode = "free" | "forbidden" | "mime";
export type WordDifficulty = "easy" | "hard" | "mixed";
export type WordCategoryChoice = WordCategory | "mixed";
export type WordEndBy = "rounds" | "target";

export interface WordTeam {
  name: string;
  players: string[];
}

export interface WordSetup {
  teams: [WordTeam, WordTeam];
  category: WordCategoryChoice;
  difficulty: WordDifficulty;
  mode: WordMode;
  turnSeconds: number;
  /** null means unlimited. */
  passLimit: number | null;
  endBy: WordEndBy;
  rounds: number;
  target: number;
}

export const WORD_MIN_TEAM = 2;
export const WORD_MAX_TEAM = 8;
export const WORD_SETUP_STORAGE_KEY = "word_game_setup";
export const WORD_MODES = ["free", "forbidden", "mime"] as const satisfies readonly WordMode[];
export const WORD_DIFFICULTIES = ["easy", "hard", "mixed"] as const satisfies readonly WordDifficulty[];
export const WORD_END_BYS = ["rounds", "target"] as const satisfies readonly WordEndBy[];
export const TURN_SECONDS = [30, 60, 90] as const;
export const PASS_LIMITS = [0, 3, null] as const;
export const ROUND_CHOICES = [1, 2, 3] as const;
export const TARGET_CHOICES = [20, 30, 50] as const;
export const WORD_CATEGORY_CHOICES: readonly WordCategoryChoice[] = ["mixed", ...WORD_CATEGORIES];

/** Team 1 and team 2. Both are light enough for `GAME_THEME.ink` text on top. */
export const WORD_TEAM_COLORS = [PLAYER_COLORS[0], PLAYER_COLORS[6]] as const;

export function teamColor(team: number): string {
  return WORD_TEAM_COLORS[team % 2];
}

export function wordSeenKey(lang: Lang): string {
  return `word_game_seen_${lang}`;
}

/** The two default team names from the translated "Team {n}". */
export function defaultTeamNames(template: string): [string, string] {
  return [template.replace("{n}", "1"), template.replace("{n}", "2")];
}

export function defaultWordSetup(teamNames: readonly [string, string]): WordSetup {
  return {
    teams: [
      { name: teamNames[0], players: [] },
      { name: teamNames[1], players: [] },
    ],
    category: "mixed",
    difficulty: "mixed",
    mode: "free",
    turnSeconds: 60,
    passLimit: 3,
    endBy: "rounds",
    rounds: 2,
    target: 30,
  };
}

export type WordSetupError = "teamSize" | "blankName" | "duplicateName" | "blankTeamName" | "sameTeamName";

export const WORD_SETUP_ERROR_KEYS = {
  teamSize: "wordErrTeamSize",
  blankName: "wordErrBlank",
  duplicateName: "wordErrDuplicate",
  blankTeamName: "wordErrTeamBlank",
  sameTeamName: "wordErrTeamSame",
} as const satisfies Record<WordSetupError, string>;

export const WORD_SETUP_STEPS = ["teams", "words", "rules"] as const;
export type WordSetupStep = (typeof WORD_SETUP_STEPS)[number];

const ERROR_STEP = {
  teamSize: "teams",
  blankName: "teams",
  duplicateName: "teams",
  blankTeamName: "teams",
  sameTeamName: "teams",
} as const satisfies Record<WordSetupError, WordSetupStep>;

export function validateWordSetup(setup: WordSetup): WordSetupError[] {
  const errors: WordSetupError[] = [];
  const { teams } = setup;
  if (teams.some((team) => team.players.length < WORD_MIN_TEAM || team.players.length > WORD_MAX_TEAM)) {
    errors.push("teamSize");
  }
  const names = teams.flatMap((team) => team.players.map((p) => p.trim()));
  if (names.some((n) => n === "")) errors.push("blankName");
  const keys = names.filter((n) => n !== "").map((n) => n.toLocaleLowerCase());
  if (new Set(keys).size !== keys.length) errors.push("duplicateName");
  const teamNames = teams.map((team) => team.name.trim().toLocaleLowerCase());
  if (teamNames.some((n) => n === "")) errors.push("blankTeamName");
  else if (teamNames[0] === teamNames[1]) errors.push("sameTeamName");
  return errors;
}

/** The `validateWordSetup` errors the given wizard step can fix. */
export function wordStepErrors(setup: WordSetup, step: WordSetupStep): WordSetupError[] {
  return validateWordSetup(setup).filter((e) => ERROR_STEP[e] === step);
}

function pickIndex(length: number, rng: Rng): number {
  return Math.min(length - 1, Math.floor(rng() * length));
}

export function shuffle<T>(list: readonly T[], rng: Rng): T[] {
  const out = [...list];
  for (let i = out.length - 1; i > 0; i--) {
    const j = pickIndex(i + 1, rng);
    [out[i], out[j]] = [out[j], out[i]];
  }
  return out;
}

export function shuffleTeams(setup: WordSetup, rng: Rng): WordSetup {
  const names = shuffle(
    setup.teams.flatMap((team) => team.players.map((p) => p.trim()).filter((p) => p !== "")),
    rng
  );
  const half = Math.ceil(names.length / 2);
  return {
    ...setup,
    teams: [
      { ...setup.teams[0], players: names.slice(0, half) },
      { ...setup.teams[1], players: names.slice(half) },
    ],
  };
}

function pick<T>(choices: readonly T[], value: unknown, fallback: T): T {
  return choices.includes(value as T) ? (value as T) : fallback;
}

function parseTeam(value: unknown, fallbackName: string): WordTeam {
  if (!value || typeof value !== "object" || Array.isArray(value)) return { name: fallbackName, players: [] };
  const v = value as Record<string, unknown>;
  const players = Array.isArray(v.players) ? v.players.filter((p): p is string => typeof p === "string") : [];
  return { name: typeof v.name === "string" ? v.name : fallbackName, players: players.slice(0, WORD_MAX_TEAM) };
}

// Saved settings come from device storage, which may hold an older shape or garbage:
// keep each field only if it is valid on its own.
export function parseSavedWordSetup(raw: string | null, teamNames: readonly [string, string]): WordSetup {
  const fallback = defaultWordSetup(teamNames);
  if (!raw) return fallback;
  let data: unknown;
  try {
    data = JSON.parse(raw);
  } catch {
    return fallback;
  }
  if (!data || typeof data !== "object" || Array.isArray(data)) return fallback;
  const d = data as Record<string, unknown>;
  const teams: unknown[] = Array.isArray(d.teams) ? d.teams : [];
  return {
    teams: [parseTeam(teams[0], teamNames[0]), parseTeam(teams[1], teamNames[1])],
    category: pick(WORD_CATEGORY_CHOICES, d.category, fallback.category),
    difficulty: pick<WordDifficulty>(WORD_DIFFICULTIES, d.difficulty, fallback.difficulty),
    mode: pick<WordMode>(WORD_MODES, d.mode, fallback.mode),
    turnSeconds: pick<number>(TURN_SECONDS, d.turnSeconds, fallback.turnSeconds),
    passLimit: pick<number | null>(PASS_LIMITS, d.passLimit, fallback.passLimit),
    endBy: pick<WordEndBy>(WORD_END_BYS, d.endBy, fallback.endBy),
    rounds: pick<number>(ROUND_CHOICES, d.rounds, fallback.rounds),
    target: pick<number>(TARGET_CHOICES, d.target, fallback.target),
  };
}

export function parseSavedSeen(raw: string | null): string[] {
  if (!raw) return [];
  try {
    const data: unknown = JSON.parse(raw);
    return Array.isArray(data) ? [...new Set(data.filter((id): id is string => typeof id === "string"))] : [];
  } catch {
    return [];
  }
}

/** One language's word lists, as `WORD_GAME_WORDS[lang]`. */
export type WordSource = Readonly<Record<WordCategory, readonly WordCard[]>>;

export const WORD_DECK_MIN = 50;

// The deck skips words this device has shown before. When the choice runs low, its part of
// the seen list is forgotten so the game still has enough words.
export function buildDeck(
  words: WordSource,
  category: WordCategoryChoice,
  difficulty: WordDifficulty,
  seen: readonly string[],
  rng: Rng
): { deck: WordCard[]; seen: string[] } {
  const categories: readonly WordCategory[] = category === "mixed" ? WORD_CATEGORIES : [category];
  const pool = categories
    .flatMap((c) => words[c])
    .filter((card) => difficulty === "mixed" || card.level === difficulty);
  const seenIds = new Set(seen);
  const unseen = pool.filter((card) => !seenIds.has(card.id));
  if (unseen.length >= WORD_DECK_MIN) return { deck: shuffle(unseen, rng), seen: [...seen] };
  const poolIds = new Set(pool.map((card) => card.id));
  return { deck: shuffle(pool, rng), seen: seen.filter((id) => !poolIds.has(id)) };
}

export const WORD_TAP_GUARD_MS = 300;

export type WordPhase = "setup" | "handoff" | "play" | "summary" | "end";
export type WordResult = "correct" | "pass" | "foul";

export const RESULT_POINTS = { correct: 1, pass: 0, foul: -1 } as const satisfies Record<WordResult, number>;

export interface TurnResult {
  card: WordCard;
  result: WordResult;
}

export interface WordGameState {
  phase: WordPhase;
  setup: WordSetup;
  /** The language of the words, fixed when the game starts. */
  lang: Lang;
  /** The lists the game draws from; null before the first start. */
  words: WordSource | null;
  deck: WordCard[];
  /** Words passed in this game that are not back in the deck yet. */
  passed: WordCard[];
  /** The word on screen during a turn. */
  card: WordCard | null;
  /** Ids shown on this device in `lang`; saved after every turn. */
  seen: string[];
  /** Finished turns. The team on turn is `turnsPlayed % 2`. */
  turnsPlayed: number;
  scores: [number, number];
  /** This turn's words in the order they were shown. */
  results: TurnResult[];
  /** null means unlimited. */
  passesLeft: number | null;
  /** When the turn's clock runs out, in ms. */
  endsAt: number;
  /** The deck ran out: the game ends after this turn. */
  outOfWords: boolean;
  /** When the last accepted tap happened, in ms. */
  lastActionAt: number;
}

/** `at` is the tap's (or, for timeUp, the clock's) timestamp in ms. */
export type WordGameAction =
  | { type: "start"; setup: WordSetup; lang: Lang; words: WordSource; seen: readonly string[]; rng: Rng; at: number }
  | { type: "begin"; at: number }
  | { type: "answer"; result: WordResult; rng: Rng; at: number }
  | { type: "timeUp"; at: number }
  | { type: "next"; at: number }
  | { type: "endGame"; at: number }
  | { type: "playAgain"; rng: Rng; at: number }
  | { type: "newGame"; at: number };

export function initialWordState(setup: WordSetup): WordGameState {
  return {
    phase: "setup",
    setup,
    lang: "en",
    words: null,
    deck: [],
    passed: [],
    card: null,
    seen: [],
    turnsPlayed: 0,
    scores: [0, 0],
    results: [],
    passesLeft: setup.passLimit,
    endsAt: 0,
    outOfWords: false,
    lastActionAt: 0,
  };
}

export function currentTeam(state: Pick<WordGameState, "turnsPlayed">): 0 | 1 {
  return state.turnsPlayed % 2 === 0 ? 0 : 1;
}

/** A team's n-th turn is played by `players[n % players.length]`. */
export function describer(state: Pick<WordGameState, "setup" | "turnsPlayed">): string {
  const { players } = state.setup.teams[currentTeam(state)];
  return players[Math.floor(state.turnsPlayed / 2) % players.length];
}

/** Checked after each pair of turns: rounds played out, or a team ahead at the target. */
export function isGameOver(setup: WordSetup, scores: readonly [number, number], turnsPlayed: number): boolean {
  if (turnsPlayed === 0 || turnsPlayed % 2 !== 0) return false;
  if (setup.endBy === "rounds") {
    const longest = Math.max(setup.teams[0].players.length, setup.teams[1].players.length);
    return turnsPlayed >= 2 * setup.rounds * longest;
  }
  return Math.max(scores[0], scores[1]) >= setup.target && scores[0] !== scores[1];
}

export function winner(scores: readonly [number, number]): 0 | 1 | null {
  if (scores[0] === scores[1]) return null;
  return scores[0] > scores[1] ? 0 : 1;
}

export function turnPoints(results: readonly TurnResult[]): number {
  return results.reduce((sum, r) => sum + RESULT_POINTS[r.result], 0);
}

export function signedPoints(points: number): string {
  return points > 0 ? `+${points}` : String(points);
}

// Every button moves the game on at once and the next screen's buttons sit where the last
// ones were, so a double tap would otherwise skip a word or a screen.
function tooSoon(state: WordGameState, at: number): boolean {
  const d = at - state.lastActionAt;
  return d >= 0 && d < WORD_TAP_GUARD_MS;
}

function markSeen(seen: string[], id: string): string[] {
  return seen.includes(id) ? seen : [...seen, id];
}

function trimTeam(team: WordTeam): WordTeam {
  return { name: team.name.trim(), players: team.players.map((p) => p.trim()) };
}

function dealGame(setup: WordSetup, lang: Lang, words: WordSource, seen: readonly string[], rng: Rng, at: number): WordGameState {
  const built = buildDeck(words, setup.category, setup.difficulty, seen, rng);
  const empty = built.deck.length === 0;
  return {
    ...initialWordState(setup),
    phase: empty ? "end" : "handoff",
    lang,
    words,
    deck: built.deck,
    seen: built.seen,
    outOfWords: empty,
    lastActionAt: at,
  };
}

export function wordGameReducer(state: WordGameState, action: WordGameAction): WordGameState {
  switch (action.type) {
    case "start": {
      if (state.phase !== "setup" || validateWordSetup(action.setup).length > 0 || tooSoon(state, action.at)) return state;
      const setup: WordSetup = { ...action.setup, teams: [trimTeam(action.setup.teams[0]), trimTeam(action.setup.teams[1])] };
      return dealGame(setup, action.lang, action.words, action.seen, action.rng, action.at);
    }
    case "begin": {
      if (state.phase !== "handoff" || tooSoon(state, action.at)) return state;
      const [card, ...deck] = state.deck;
      if (!card) return { ...state, phase: "end", outOfWords: true, lastActionAt: action.at };
      return {
        ...state,
        phase: "play",
        card,
        deck,
        seen: markSeen(state.seen, card.id),
        results: [],
        passesLeft: state.setup.passLimit,
        endsAt: action.at + state.setup.turnSeconds * 1000,
        lastActionAt: action.at,
      };
    }
    case "answer": {
      const { card } = state;
      if (state.phase !== "play" || !card || tooSoon(state, action.at) || action.at >= state.endsAt) return state;
      const pass = action.result === "pass";
      if (pass && state.passesLeft === 0) return state;
      const scores: [number, number] = [...state.scores];
      scores[currentTeam(state)] += RESULT_POINTS[action.result];
      let deck = state.deck;
      let passed = pass ? [...state.passed, card] : state.passed;
      if (deck.length === 0) {
        deck = shuffle(passed, action.rng);
        passed = [];
      }
      const [nextCard, ...rest] = deck;
      const answered: WordGameState = {
        ...state,
        scores,
        results: [...state.results, { card, result: action.result }],
        passesLeft: pass && state.passesLeft !== null ? state.passesLeft - 1 : state.passesLeft,
        lastActionAt: action.at,
      };
      if (!nextCard) return { ...answered, phase: "summary", card: null, deck: [], passed: [], outOfWords: true };
      return { ...answered, card: nextCard, deck: rest, passed, seen: markSeen(state.seen, nextCard.id) };
    }
    case "timeUp":
      // Not tap-guarded: the clock ends the turn even right after a tap.
      if (state.phase !== "play" || action.at < state.endsAt) return state;
      return {
        ...state,
        phase: "summary",
        card: null,
        deck: state.card ? [...state.deck, state.card] : state.deck,
        lastActionAt: action.at,
      };
    case "next": {
      if (state.phase !== "summary" || tooSoon(state, action.at)) return state;
      const turnsPlayed = state.turnsPlayed + 1;
      const over = state.outOfWords || isGameOver(state.setup, state.scores, turnsPlayed);
      return { ...state, phase: over ? "end" : "handoff", turnsPlayed, lastActionAt: action.at };
    }
    case "endGame":
      if ((state.phase !== "handoff" && state.phase !== "summary") || tooSoon(state, action.at)) return state;
      return { ...state, phase: "end", lastActionAt: action.at };
    case "playAgain":
      if (state.phase !== "end" || !state.words || tooSoon(state, action.at)) return state;
      return dealGame(state.setup, state.lang, state.words, state.seen, action.rng, action.at);
    case "newGame":
      if (state.phase !== "end" || tooSoon(state, action.at)) return state;
      // The setup's Start can sit where New game was: keep the time so Start is guarded too.
      return { ...initialWordState(state.setup), lastActionAt: action.at };
  }
}

"use client";

import { useEffect, useState } from "react";
import { useLang } from "@/lib/i18n";
import {
  GAME_THEME,
  WORD_COLORS,
  WORD_TIME_UP_MS,
  WORD_WARN_SECONDS,
  formatCountdown,
  remainingSeconds,
  type WordCard,
  type WordMode,
  type WordResult,
} from "@/lib/word-game";

// The describer's screen. Mount it with `key` per turn so the clock starts fresh; the
// parent passes a stable `onTimeUp`, or the pause before it would restart on every render.
export default function WordTurn({
  card,
  mode,
  endsAt,
  passLimit,
  passesLeft,
  onAnswer,
  onTimeUp,
}: {
  card: WordCard;
  mode: WordMode;
  endsAt: number;
  passLimit: number | null;
  passesLeft: number | null;
  onAnswer: (result: WordResult) => void;
  onTimeUp: () => void;
}) {
  const { t } = useLang();
  const [now, setNow] = useState(() => Date.now());

  useEffect(() => {
    const id = setInterval(() => setNow(Date.now()), 250);
    return () => clearInterval(id);
  }, []);

  const left = remainingSeconds(endsAt, now);
  const over = left === 0;
  const warn = left <= WORD_WARN_SECONDS;

  useEffect(() => {
    if (!over) return;
    const id = setTimeout(onTimeUp, WORD_TIME_UP_MS);
    return () => clearTimeout(id);
  }, [over, onTimeUp]);

  // The text changes only twice per turn, so it is read out only then.
  const announcement = over ? t.wordTimeUp : warn ? t.wordSecondsLeft.replace("{n}", String(WORD_WARN_SECONDS)) : "";
  const answer = "flex-1 rounded-xl border-2 py-4 text-lg font-bold disabled:opacity-40";
  const ink = { color: GAME_THEME.ink, borderColor: GAME_THEME.bg };

  return (
    <div className="space-y-4 text-center">
      <p
        role="timer"
        className={`mx-auto w-fit rounded-full px-6 py-1 font-mono text-5xl font-bold ${warn && !over ? "animate-pulse" : ""}`}
        style={{ backgroundColor: GAME_THEME.bg, color: warn ? WORD_COLORS.warn : GAME_THEME.text }}
      >
        {formatCountdown(left)}
      </p>
      <p aria-live="assertive" className="sr-only">
        {announcement}
      </p>
      <div
        data-card
        className="flex min-h-72 flex-col items-center justify-center gap-4 rounded-2xl p-6"
        style={{ backgroundColor: GAME_THEME.bg, color: GAME_THEME.text }}
      >
        {over ? (
          <p className="text-4xl font-bold">{t.wordTimeUp}</p>
        ) : (
          <div key={card.id} className="animate-[game-fade_150ms_ease-out] space-y-4">
            <p className="break-words text-4xl font-bold">{card.word}</p>
            {mode === "forbidden" ? (
              <div className="space-y-1">
                <p className="text-xs uppercase tracking-wide" style={{ color: GAME_THEME.muted }}>
                  {t.wordForbiddenLabel}
                </p>
                <ul className="space-y-1 text-xl font-semibold" style={{ color: WORD_COLORS.warn }}>
                  {card.forbidden.map((word) => (
                    <li key={word}>{word}</li>
                  ))}
                </ul>
              </div>
            ) : (
              <p style={{ color: GAME_THEME.muted }}>{mode === "mime" ? t.wordNoTalking : t.wordFreeHint}</p>
            )}
          </div>
        )}
      </div>
      <div className="flex gap-2">
        <button
          type="button"
          disabled={over}
          onClick={() => onAnswer("foul")}
          className={answer}
          style={{ ...ink, backgroundColor: WORD_COLORS.foul }}
        >
          {t.wordFoul}
        </button>
        {passLimit !== 0 && (
          <button
            type="button"
            disabled={over || passesLeft === 0}
            onClick={() => onAnswer("pass")}
            aria-label={passesLeft === null ? t.wordPass : t.wordPassesLeft.replace("{n}", String(passesLeft))}
            className={answer}
            style={{ ...ink, backgroundColor: WORD_COLORS.pass }}
          >
            {passesLeft === null ? t.wordPass : `${t.wordPass} (${passesLeft})`}
          </button>
        )}
        <button
          type="button"
          disabled={over}
          onClick={() => onAnswer("correct")}
          className={answer}
          style={{ ...ink, backgroundColor: WORD_COLORS.correct }}
        >
          {t.wordCorrect}
        </button>
      </div>
    </div>
  );
}

import { useLang } from "@/lib/i18n";
import {
  PASS_LIMITS,
  ROUND_CHOICES,

  `flex-1 rounded-md px-3 py-2 text-sm transition ${active ? "bg-surface font-semibold text-gray-900 shadow-sm" : "text-gray-500"}`;

function choice<T>(label: string, options: readonly { value: T; label: string }[], value: T, onPick: (value: T) => void) {
  return (
    <div role="group" aria-label={label} className="space-y-2">
      <h3 className="text-sm font-medium text-gray-500">{label}</h3>
      <div className="flex rounded-lg bg-gray-100 p-1">
        {options.map((o) => (
          <button
            key={String(o.value)}
            type="button"
            aria-pressed={o.value === value}
            className={pill(o.value === value)}
            onClick={() => onPick(o.value)}
          >
            {o.label}
          </button>
        ))}
      </div>
    </div>
  );
}

export default function WordRulesStep({

  onChange,

  onChange: (next: WordSetup) => void;

                active ? "border-white" : "border-gray-100 opacity-60 hover:opacity-90"
              }`}
            >
              <span className="block font-semibold text-gray-900">{t[WORD_MODE_KEYS[mode].label]}</span>
              <span className="block text-sm text-gray-500">{t[WORD_MODE_KEYS[mode].rule]}</span>
            </button>
          );
        })}
      </div>
      {choice(
        t.wordTurnTime,
        TURN_SECONDS.map((n): { value: number; label: string } => ({ value: n, label: t.wordSeconds.replace("{n}", String(n)) })),
        value.turnSeconds,
        (turnSeconds) => set({ turnSeconds })
      )}
      {choice(
        t.wordPasses,
        PASS_LIMITS.map((n): { value: number | null; label: string } => ({
          value: n,
          label: n === null ? t.wordPassesUnlimited : String(n),
        })),
        value.passLimit,
        (passLimit) => set({ passLimit })

        t.wordEndBy,

        (endBy) => set({ endBy })

        ? choice(t.wordRounds, numbers(ROUND_CHOICES), value.rounds, (rounds) => set({ rounds }))
        : choice(t.wordTarget, numbers(TARGET_CHOICES), value.target, (target) => set({ target }))}

  );

"use client";

import { useLang } from "@/lib/i18n";
import { playerColor } from "@/lib/imposter";
import {
  GAME_THEME,
  WORD_SETUP_ERROR_KEYS,
  WORD_SETUP_STEPS,
  validateWordSetup,
  wordStepErrors,
  type WordSetup,
} from "@/lib/word-game";
import WordRulesStep from "./WordRulesStep";
import WordTeamsStep from "./WordTeamsStep";
import WordWordsStep from "./WordWordsStep";

// The setup, one step at a time. The step lives in the parent so this component has no
// state of its own.
export default function WordSetupWizard({
  value,
  onChange,
  step,
  onStep,
  onStart,
  quickStart,
}: {
  value: WordSetup;
  onChange: (next: WordSetup) => void;
  /** Index into WORD_SETUP_STEPS. */
  step: number;
  onStep: (step: number) => void;
  onStart: () => void;
  /** A game was played on this device before: offer to skip the remaining steps. */
  quickStart: boolean;
}) {
  const { t } = useLang();
  const name = WORD_SETUP_STEPS[step];
  const last = step === WORD_SETUP_STEPS.length - 1;
  const allErrors = validateWordSetup(value);
  // The last step shows everything that still blocks Start, whichever step it belongs to.
  const errors = last ? allErrors : wordStepErrors(value, name);
  const titles = { teams: t.wordStepTeams, words: t.wordStepWords, rules: t.wordStepRules };
  const primary = "flex-1 rounded-lg bg-blue-600 py-3 font-semibold text-white hover:bg-blue-700 disabled:opacity-50";

  return (
    <div className="space-y-5">
      <div className="flex items-center justify-between">
        <h2 className="text-lg font-bold text-gray-900">{titles[name]}</h2>
        <div
          className="flex gap-1.5"
          role="img"
          aria-label={t.wordStep.replace("{n}", String(step + 1)).replace("{total}", String(WORD_SETUP_STEPS.length))}
        >
          {WORD_SETUP_STEPS.map((s, i) => (
            <span key={s} className={`h-2 w-2 rounded-full ${i === step ? "bg-white" : "bg-white/30"}`} />
          ))}
        </div>
      </div>

      {name === "teams" && <WordTeamsStep value={value} onChange={onChange} />}
      {name === "words" && <WordWordsStep value={value} onChange={onChange} />}
      {name === "rules" && <WordRulesStep value={value} onChange={onChange} />}

      {errors.length > 0 && (
        <ul role="alert" className="space-y-1 rounded-lg bg-amber-50 p-3 text-sm text-amber-700 dark:text-amber-400">
          {errors.map((e) => (
            <li key={e}>{t[WORD_SETUP_ERROR_KEYS[e]]}</li>
          ))}
        </ul>
      )}

      <div className="flex gap-3">
        {step > 0 && (
          <button
            type="button"
            onClick={() => onStep(step - 1)}
            className="flex-1 rounded-lg border border-gray-200 py-3 text-gray-600 hover:bg-gray-100"
          >
            {t.back}
          </button>
        )}
        {last ? (
          <button type="button" disabled={allErrors.length > 0} onClick={onStart} className={primary}>
            {t.wordStart}
          </button>
        ) : (
          <button type="button" disabled={errors.length > 0} onClick={() => onStep(step + 1)} className={primary}>
            {t.wordNext}
          </button>
        )}
      </div>

      {step === 0 && quickStart && allErrors.length === 0 && (
        <button
          type="button"
          onClick={onStart}
          className="w-full rounded-lg py-3 font-semibold"
          style={{ backgroundColor: playerColor(2), color: GAME_THEME.ink }}
        >
          {t.wordQuickStart}
        </button>
      )}
    </div>
  );
}

import WordSummary from "./WordSummary";

function read(key: string): string | null {
  try {
    return localStorage.getItem(key);
  } catch {
    return null;
  }
}

function write(key: string, value: string) {
  try {
    localStorage.setItem(key, value);
  } catch {
    // Private mode or full storage: the game still runs, it just forgets.
  }
}

// Returns only other components, never a host element: its test renders it without a DOM.
export default function WordGame() {
  const { t, lang } = useLang();
  // The default team names follow the language the page opened in.
  const [teamNames] = useState(() => defaultTeamNames(t.wordTeamDefault));
  const [state, dispatch] = useReducer(wordGameReducer, undefined, () => initialWordState(defaultWordSetup(teamNames)));
  const [draft, setDraft] = useState<WordSetup>(() => defaultWordSetup(teamNames));
  const [step, setStep] = useState(0);
  // A game was played on this device before: the wizard may offer to skip its steps.
  const [played, setPlayed] = useState(false);
  const timeUp = useCallback(() => dispatch({ type: "timeUp", at: Date.now() }), []);

  // Read after mount: localStorage does not exist during prerendering.
  useEffect(() => {
    const saved = parseSavedWordSetup(read(WORD_SETUP_STORAGE_KEY), teamNames);
    // eslint-disable-next-line react-hooks/set-state-in-effect
    setDraft(saved);
    setPlayed(validateWordSetup(saved).length === 0);
  }, [teamNames]);

  const { phase, setup, words, seen } = state;
  useEffect(() => {
    if (words && (phase === "summary" || phase === "end")) write(wordSeenKey(state.lang), JSON.stringify(seen));
  }, [phase, words, seen, state.lang]);

  const team = currentTeam(state);

  if (phase === "setup") {
    return (
      <GameFrame>
        <WordSetupWizard
          value={draft}
          onChange={setDraft}
          step={step}
          onStep={setStep}
          quickStart={played}
          onStart={() => {
            write(WORD_SETUP_STORAGE_KEY, JSON.stringify(draft));
            setPlayed(true);
            setStep(0);
            dispatch({
              type: "start",
              setup: draft,
              lang,
              words: WORD_GAME_WORDS[lang],
              seen: parseSavedSeen(read(wordSeenKey(lang))),
              rng: Math.random,
              at: Date.now(),
            });
          }}
        />
      </GameFrame>
    );
  }

  if (phase === "handoff") {
    return (
      <GameFrame color={teamColor(team)}>
        <WordHandoff
          describer={describer(state)}
          teamName={setup.teams[team].name}
          teams={setup.teams}
          scores={state.scores}
          onBegin={() => dispatch({ type: "begin", at: Date.now() })}
          onEnd={() => dispatch({ type: "endGame", at: Date.now() })}
        />
      </GameFrame>
    );
  }

  if (phase === "play") {
    if (!state.card) return null;
    return (
      <GameFrame color={teamColor(team)}>
        <WordTurn
          key={state.turnsPlayed}
          card={state.card}
          mode={setup.mode}
          endsAt={state.endsAt}
          passLimit={setup.passLimit}
          passesLeft={state.passesLeft}
          onAnswer={(result) => dispatch({ type: "answer", result, rng: Math.random, at: Date.now() })}
          onTimeUp={timeUp}
        />
      </GameFrame>
    );
  }

  if (phase === "summary") {
    return (
      <GameFrame>
        <WordSummary
          team={team}
          teams={setup.teams}
          scores={state.scores}
          results={state.results}
          outOfWords={state.outOfWords}
          onNext={() => dispatch({ type: "next", at: Date.now() })}
          onEnd={() => dispatch({ type: "endGame", at: Date.now() })}
        />
      </GameFrame>
    );
  }

  return (
    <GameFrame>
      <WordEnd
        teams={setup.teams}
        scores={state.scores}
        outOfWords={state.outOfWords}
        onPlayAgain={() => dispatch({ type: "playAgain", rng: Math.random, at: Date.now() })}
        onNewGame={() => {
          setDraft(state.setup);
          dispatch({ type: "newGame", at: Date.now() });
        }}
      />
    </GameFrame>
  );
}

import AsyncStorage from "@react-native-async-storage/async-storage";
import type { Lang } from "@ptracker/shared/i18n";
import {
  WORD_SETUP_STORAGE_KEY,
  defaultWordSetup,
  parseSavedSeen,
  parseSavedWordSetup,
  wordSeenKey,
  type WordSetup,
} from "@ptracker/shared/word-game";

// The word game's settings and its seen list per language. Fail-soft like
// imposter-storage.ts: a storage error means defaults, never a game that will not open.

export async function getStoredWordSetup(teamNames: readonly [string, string]): Promise<WordSetup> {
  try {
    return parseSavedWordSetup(await AsyncStorage.getItem(WORD_SETUP_STORAGE_KEY), teamNames);
  } catch {
    return defaultWordSetup(teamNames);
  }
}

export async function setStoredWordSetup(setup: WordSetup): Promise<void> {
  try {
    await AsyncStorage.setItem(WORD_SETUP_STORAGE_KEY, JSON.stringify(setup));
  } catch {
    // Non-fatal: the game runs, the teams just are not remembered.
  }
}

export async function getStoredSeen(lang: Lang): Promise<string[]> {
  try {
    return parseSavedSeen(await AsyncStorage.getItem(wordSeenKey(lang)));
  } catch {
    return [];
  }
}

export async function setStoredSeen(lang: Lang, seen: readonly string[]): Promise<void> {
  try {
    await AsyncStorage.setItem(wordSeenKey(lang), JSON.stringify(seen));
  } catch {
    // Non-fatal: words may come back sooner.
  }
}

import { useEffect, useRef, useState } from "react";
import { AccessibilityInfo, Pressable, Text, View } from "react-native";
import Animated, { ZoomIn } from "react-native-reanimated";

import { useLang } from "@ptracker/shared/i18n";
import {
  GAME_THEME,
  WORD_COLORS,
  WORD_TIME_UP_MS,
  WORD_WARN_SECONDS,
  formatCountdown,
  remainingSeconds,
  type WordCard,
  type WordMode,
  type WordResult,
} from "@ptracker/shared/word-game";

// The describer's screen. Render it in a GameScreen with `scroll={false}` on the team's
// colour, mount it with `key` per turn so the clock starts fresh, and pass a stable
// `onTimeUp`, or the pause before it would restart on every render.
export function WordTurn({
  card,
  mode,
  endsAt,
  passLimit,
  passesLeft,
  onAnswer,
  onTimeUp,
}: {
  card: WordCard;
  mode: WordMode;
  endsAt: number;
  passLimit: number | null;
  passesLeft: number | null;
  onAnswer: (result: WordResult) => void;
  onTimeUp: () => void;
}) {
  const { t } = useLang();
  const [now, setNow] = useState(() => Date.now());
  // Each stage is read out once, however often the effect runs.
  const announced = useRef<"warn" | "over" | null>(null);

  useEffect(() => {
    const id = setInterval(() => setNow(Date.now()), 250);
    return () => clearInterval(id);
  }, []);

  const left = remainingSeconds(endsAt, now);
  const over = left === 0;
  const warn = left <= WORD_WARN_SECONDS;

  useEffect(() => {
    const stage = over ? "over" : warn ? "warn" : null;
    if (!stage || announced.current === stage) return;
    announced.current = stage;
    AccessibilityInfo.announceForAccessibility(
      stage === "over" ? t.wordTimeUp : t.wordSecondsLeft.replace("{n}", String(WORD_WARN_SECONDS))
    );
  }, [over, warn, t]);

  useEffect(() => {
    if (!over) return;
    const id = setTimeout(onTimeUp, WORD_TIME_UP_MS);
    return () => clearTimeout(id);
  }, [over, onTimeUp]);

  const clock = (
    <Text
      accessibilityRole="timer"
      className="text-5xl font-bold"
      style={{ color: warn ? WORD_COLORS.warn : GAME_THEME.text, fontVariant: ["tabular-nums"] }}>
      {formatCountdown(left)}
    </Text>
  );

  const answerButton = (result: WordResult, label: string, color: string, disabled: boolean, accessibilityLabel = label) => (
    <Pressable
      key={result}
      accessibilityRole="button"
      accessibilityLabel={accessibilityLabel}
      accessibilityState={{ disabled }}
      disabled={disabled}
      onPress={() => onAnswer(result)}
      className={`flex-1 items-center rounded-xl border-2 py-5 ${disabled ? "opacity-40" : ""}`}
      style={{ backgroundColor: color, borderColor: GAME_THEME.bg }}>
      <Text className="text-lg font-bold" style={{ color: GAME_THEME.ink }}>
        {label}
      </Text>
    </Pressable>
  );

  return (
    <View className="flex-1 justify-between gap-4 py-2">
      <View className="items-center">
        <View className="rounded-full px-6 py-1" style={{ backgroundColor: GAME_THEME.bg }}>
          {warn && !over ? (
            <Animated.View key={left} entering={ZoomIn.duration(200)}>

// The setup, one step at a time. The step lives in the parent so this component has no
// state of its own.
export function WordSetupWizard({
  value,
  onChange,
  step,
  onStep,
  onStart,
  quickStart,
}: {
  value: WordSetup;
  onChange: (next: WordSetup) => void;
  /** Index into WORD_SETUP_STEPS. */
  step: number;
  onStep: (step: number) => void;
  onStart: () => void;
  /** A game was played on this device before: offer to skip the remaining steps. */
  quickStart: boolean;
}) {
  const { t } = useLang();
  const name = WORD_SETUP_STEPS[step];
  const last = step === WORD_SETUP_STEPS.length - 1;
  const allErrors = validateWordSetup(value);
  // The last step shows everything that still blocks Start, whichever step it belongs to.
  const errors = last ? allErrors : wordStepErrors(value, name);
  const titles = { teams: t.wordStepTeams, words: t.wordStepWords, rules: t.wordStepRules };

  return (
    <View className="gap-5">
      <View className="flex-row items-center justify-between">
        <Text className="text-xl font-bold text-gray-900">{titles[name]}</Text>
        <View
          className="flex-row gap-1.5"
          accessible
          accessibilityLabel={t.wordStep.replace("{n}", String(step + 1)).replace("{total}", String(WORD_SETUP_STEPS.length))}>
          {WORD_SETUP_STEPS.map((s, i) => (
            <View
              key={s}
              className="h-2 w-2 rounded-full"
              style={{ backgroundColor: GAME_THEME.text, opacity: i === step ? 1 : 0.3 }}
            />
          ))}
        </View>
      </View>

      {name === "teams" ? <WordTeamsStep value={value} onChange={onChange} /> : null}
      {name === "words" ? <WordWordsStep value={value} onChange={onChange} /> : null}
      {name === "rules" ? <WordRulesStep value={value} onChange={onChange} /> : null}

      {errors.length > 0 ? (
        <View className="gap-1 rounded-lg bg-amber-50 p-3" accessibilityRole="alert" accessibilityLiveRegion="polite">
          {errors.map((e) => (
            <Text key={e} className="text-sm text-amber-700">
              {t[WORD_SETUP_ERROR_KEYS[e]]}
            </Text>
          ))}
        </View>
      ) : null}

      <View className="flex-row items-center gap-3">
        {step > 0 ? (
          <Pressable accessibilityRole="button" onPress={() => onStep(step - 1)} className="flex-1 rounded-lg border border-gray-200 py-3">
            <Text className="text-center text-base text-gray-600">{t.back}</Text>
          </Pressable>
        ) : null}
        <View className="flex-1">
          {last ? (
            <PrimaryButton label={t.wordStart} onPress={onStart} disabled={allErrors.length > 0} />

          )}

          <Text className="text-center text-base font-semibold" style={{ color: GAME_THEME.ink }}>
            {t.wordQuickStart}
          </Text>
        </Pressable>
      ) : null}
    </View>
  );

import { useCallback, useEffect, useReducer, useState, type ReactNode } from "react";
import { ActivityIndicator } from "react-native";

import { useLang } from "@ptracker/shared/i18n";
import {
  currentTeam,
  defaultTeamNames,
  defaultWordSetup,
  describer,
  initialWordState,
  teamColor,
  validateWordSetup,
  wordGameReducer,
  type WordSetup,
} from "@ptracker/shared/word-game";
import { WORD_GAME_WORDS } from "@ptracker/shared/word-game-words";
import { GamesPinSetup, useEnterGameModeOnce } from "@/components/games/game-mode-entry";
import { GameScreen } from "@/components/games/game-screen";
import { WordEnd } from "@/components/games/word/word-end";
import { WordHandoff } from "@/components/games/word/word-handoff";
import { WordSetupWizard } from "@/components/games/word/word-setup";
import { WordSummary } from "@/components/games/word/word-summary";
import { WordTurn } from "@/components/games/word/word-turn";
import { getStoredSeen, getStoredWordSetup, setStoredSeen, setStoredWordSetup } from "@/lib/word-game-storage";

export default function WordScreen() {
  const { t, lang } = useLang();
  // The default team names follow the language the screen opened in.
  const [teamNames] = useState(() => defaultTeamNames(t.wordTeamDefault));
  const [state, dispatch] = useReducer(wordGameReducer, undefined, () => initialWordState(defaultWordSetup(teamNames)));
  const [draft, setDraft] = useState<WordSetup | null>(null);
  // This device's seen list in `lang`. Updated on every save, so the next game never starts
  // from a copy older than the last turn.
  const [seen, setSeen] = useState<string[] | null>(null);
  const [step, setStep] = useState(0);
  // A game was played on this device before: the wizard may offer to skip its steps.
  const [played, setPlayed] = useState(false);
  const pinReady = useEnterGameModeOnce();
  const timeUp = useCallback(() => dispatch({ type: "timeUp", at: Date.now() }), []);

  useEffect(() => {
    getStoredWordSetup(teamNames).then((saved) => {
      setDraft(saved);
      setPlayed(validateWordSetup(saved).length === 0);
    });
  }, [teamNames]);

  useEffect(() => {
    let live = true;
    getStoredSeen(lang).then((ids) => {
      if (live) setSeen(ids);
    });
    return () => {
      live = false;
    };
  }, [lang]);

  const { phase, setup, words } = state;
  useEffect(() => {
    if (!words || (phase !== "summary" && phase !== "end")) return;
    void setStoredSeen(state.lang, state.seen);
    if (state.lang === lang) setSeen(state.seen);
  }, [phase, words, state.lang, state.seen, lang]);

  if (!pinReady) return <GamesPinSetup title={t.wordTitle} />;

  const team = currentTeam(state);
  let body: ReactNode = null;

  if (phase === "setup") {
    body =
      draft && seen ? (
        <WordSetupWizard
          value={draft}
          onChange={setDraft}
          step={step}
          onStep={setStep}
          quickStart={played}
          onStart={() => {
            void setStoredWordSetup(draft);
            setPlayed(true);
            setStep(0);
            dispatch({ type: "start", setup: draft, lang, words: WORD_GAME_WORDS[lang], seen, rng: Math.random, at: Date.now() });
          }}
        />
      ) : (
        <ActivityIndicator />
      );
  } else if (phase === "handoff") {
    body = (
      <WordHandoff
        describer={describer(state)}
        teamName={setup.teams[team].name}
        teams={setup.teams}
        scores={state.scores}
        onBegin={() => dispatch({ type: "begin", at: Date.now() })}
        onEnd={() => dispatch({ type: "endGame", at: Date.now() })}
      />
    );
  } else if (phase === "play" && state.card) {
    body = (
      <WordTurn
        key={state.turnsPlayed}
        card={state.card}
        mode={setup.mode}
        endsAt={state.endsAt}
        passLimit={setup.passLimit}
        passesLeft={state.passesLeft}
        onAnswer={(result) => dispatch({ type: "answer", result, rng: Math.random, at: Date.now() })}
        onTimeUp={timeUp}
      />
    );
  } else if (phase === "summary") {
    body = (
      <WordSummary
        team={team}
        teams={setup.teams}
        scores={state.scores}
        results={state.results}
        outOfWords={state.outOfWords}
        onNext={() => dispatch({ type: "next", at: Date.now() })}
        onEnd={() => dispatch({ type: "endGame", at: Date.now() })}
      />
    );
  } else if (phase === "end") {
    body = (
      <WordEnd
        teams={setup.teams}
        scores={state.scores}
        outOfWords={state.outOfWords}
        onPlayAgain={() => dispatch({ type: "playAgain", rng: Math.random, at: Date.now() })}
        onNewGame={() => {
          setDraft(state.setup);
          dispatch({ type: "newGame", at: Date.now() });
        }}
      />
    );
  }

  // The hand-over and the turn belong to one team: the screen takes that team's colour.
  const teamTurn = phase === "handoff" || phase === "play";
  return (
    <GameScreen
      title={t.wordTitle}
      tone="game"
      color={teamTurn ? teamColor(team) : undefined}
      scroll={phase !== "play"}>
      {body}
    </GameScreen>
  );
}
