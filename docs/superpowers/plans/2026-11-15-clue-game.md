# One Clue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for every task: write the failing test, watch it fail, implement, watch it pass, commit.

**Goal:** Add One Clue (TR Tek İpucu), a cooperative word game, to the Games section on web and mobile, offline like the other games.

**Architecture:** All rules live in the pure module `shared/clue-game.ts`: setup defaults, validation, `parseSavedClueSetup` / `parseSavedClueSeen`, deck building from word lists passed in, clue validation, normalisation and automatic striking, and a reducer (`setup → handoff → clue → check → guess → result → end`) whose actions carry their time (`at`) and whose randomness comes from an injected `Rng`. It imports only `shared/word-game-words/types.ts` and the list-free `shared/word-game.ts`, never a word list. Only the game containers (web `ClueGame`, mobile `app/games/clue.tsx`) import `word-game-words`, so the lists ship with the game's route.

**Tech stack:** Next.js 16 client components with Tailwind v4, Expo SDK 57 with NativeWind 4 and expo-router, vitest in the node environment (components are called as functions or rendered through react-dom into a fake container).

**Spec:** `docs/superpowers/specs/2026-11-15-clue-game-design.md`

## Decisions (the spec leaves them open)

1. **Setup:** `{ players, deckSize: 8 | 13 | 20, level: "easy" | "hard" | "mixed" }`, default 13 / Mixed. 3–10 players (`CLUE_MIN_PLAYERS`, `CLUE_MAX_PLAYERS`); Imposter's strings for too few, blank and duplicate names, an own `clueErrTooMany`. `parseSavedClueSetup` keeps each valid field and at most 10 names. Wizard steps `players`, `rules`.
2. **Pool and deck:** every Describe It category but `idioms`, filtered by level. The deck is the first `deckSize` of `[shuffle(unseen), shuffle(seen)]`; when fewer than `deckSize` are unseen, the pool's ids leave the seen list. A word joins the seen list when its round starts; the seen list (`clue_seen_<lang>`) is saved on `result` and `end`. A pool smaller than the deck size gives a shorter game; an empty one refuses Start.
3. **Turn order:** `turns` counts finished rounds since the setup and survives Play again; the guesser is `players[turns % n]`, the clue givers the others in seat order after them. New game resets it.
4. **Privacy in the reducer:** `clue`, `check` and `guess` each start hidden (`revealed: false`); a tap-guarded `reveal` shows them. The guesser's screens (handoff, the guess hand-off and the guess) never get the word as a prop; the guess screen gets only the surviving clue texts.
5. **Clue rules:** trimmed; refused when empty, with whitespace inside, longer than 24 characters, or without a letter or digit (an emoji or `?!` would normalise to nothing and strike or match by accident). The key is lowercased with the game language's locale, decomposed with `normalize("NFKD")` where it exists, folded through a small table (Turkish letters and common Latin accents, `ı` → `i`, so it works without `normalize`), and kept to letters (told by having a case) and digits; no Unicode property escapes.
6. **Striking:** on entering `check`, a clue whose key equals another's is struck (`duplicate`), and one whose key contains the word's key or is contained in it is struck (`word`). Each clue stores `struck` (toggled freely by taps) and `auto` (the reason, for the label). A clue struck by hand reads "struck by the table".
7. **Guess:** Got it (+1), Missed and Pass (0). With no surviving clue the reducer accepts only Pass.
8. **Screens and colours:** handoff and guess on the guesser's colour, the clue screen on the giver's colour (`PassPhone` gate), setup, check, result and end on the game's dark background. Check and guess open behind a gate (`ClueGate`) that names who may look. The clue screen is keyed by round and giver, so the field starts empty for each giver.
9. **End:** "9 of 13", a rating line by share guessed (all, ≥ 3/4, ≥ 1/2, ≥ 1/4, less), the words with ✓ / ✕ / ↷ and their label, Play again (same players and rules, new words, rotation carried), New game.
10. **Games list:** web lucide `Lightbulb` on `bg-sky-50`, icon `text-sky-600 dark:text-sky-400`, `hover:border-sky-200` (add `--color-sky-50` and `--color-sky-200` to `.dark` in `globals.css`); mobile 💡 on `bg-sky-50` (themed in `mobile/tailwind.config.js`, `mobile/tailwind.css` and `GAME_DARK_TOKENS`).
